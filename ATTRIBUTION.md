# Attribution guide

When you publish a fork, derivative work, tutorial, video, article, or integration
that substantially uses JobClaw, use a visible attribution such as:

> Based on JobClaw by Chris — https://github.com/YanQuan-dozzy/Boss-Claw.git

For source distributions, retain `LICENSE` and `NOTICE`, and clearly describe
material changes. For videos and articles, put the attribution in the description
or credits.

Please also notify the author through a GitHub Issue. Notification is strongly
requested for collaboration and credit tracking, but is not an additional condition
of the Apache License 2.0.
