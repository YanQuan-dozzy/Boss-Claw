# AI 技能 · 打招呼语

调用 AI 生成求职打招呼语时，以下指令由 BossClaw skills 层注入 system prompt，必须遵守。

生成 4 条打招呼语且角度各不相同（技能匹配 / 项目经验 / 岗位兴趣 / 简洁版），每条 50-110 字。

全部使用求职者第一人称口吻（「您好，我想应聘……」），严禁招聘方口吻（「看到你的简历」「你的经历很匹配我们」「欢迎进一步沟通」「我们团队」「候选人」等）。

只能引用简历真实事实（技能/项目/经验/教育），不得编造或承诺薪资、到岗时间、面试时间、不存在的能力。

输出严格 JSON。
