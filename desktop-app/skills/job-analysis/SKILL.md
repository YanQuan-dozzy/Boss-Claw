# AI 技能 · 岗位匹配评估

调用 AI 分析岗位匹配度时，以下指令由 BossClaw skills 层注入 system prompt，必须遵守。

评分必须稳定（同一岗位重复分析波动 ≤±5）且与决策档位一致（推荐 >80 / 匹配 65-80 / 谨慎 50-64 / 不推荐 <50），严禁所有岗位挤在 60-70 之间。

**严格区分（防止人人高分的唯一闸门，优先级高于其它措辞）**：match/strong 只授予「核心技能**直接命中** + 方向**高度同向** + 无明显影响上手的实质缺口」的岗位。凡核心职责依赖「技术栈可迁移 / 能补位 / 需现学 / 简历无任何同类擅做项目经历」才能胜任的，**一律不得判 match**，划到 cautious（score 50-64，按缺口严重度可低至 40-49）。「方向与标题一并对口但技能栈仅沾边可迁移」与「核心技能直接命中」必须拉开分数：前者 ≤64，后者才可给 65+。宁可把「差不多」的岗位降到谨慎、让推荐档也有区分度，也不要把每个对口标题都打 70 分。

## 维度评分（dimensionScores）

除整体档位与分数外，必须输出五个固定维度的语义评估分，每项 `{score: 0-100 整数, evidence: 一句 ≤30 字依据}`：

| 维度 | 评分口径 |
|:---|:---|
| skill 技能 | JD 要求 vs 简历真实技能栈整体覆盖度；同义/同族已覆盖不算缺口（Git 覆盖 GitHub/GitLab、FastAPI 覆盖 Flask/Django、TypeScript/React 覆盖 JavaScript）；**根本性技术栈错位**（岗位核心语言/框架与简历完全不同族且无法迁移，如岗位要求 C++/C#/Rust/Go/嵌入式、简历只有 Java/JavaScript/Python 业务开发；或岗位要求精通某语言而简历任何技能/经历/项目均未使用）→ **≤25 且整体档位不得高于谨慎**；同族可迁移（Python↔Java、React↔Vue、MySQL↔PostgreSQL）→ 50-70 并写明可迁移依据；核心技能直接命中 → 85+；部分缺失按缺口严重度扣分、表达缺口从轻；严禁编造 |
| direction 方向 | 岗位标题/职责与画像主方向/搜索词的语义一致度；标题强命中 80+，方向错位低分 |
| salary 薪资 | 一律以本地校准信息的岗位薪资及折算值为准：明显低于期望下限 ≤30 / 达到或高于期望 90-100 / 部分重叠按比例 / 期望未设或面议 60-70 |
| education 学历 | 达标 100 / 高于要求 90 / 不达标 ≤30 / JD 未要求 70 |
| experience 经验 | 年限比例 ≥1.0 → 100 / 0.8+ → 85 / 0.6+ → 65 / 0.4+ → 45 / 以下 → 30 / JD 未要求 65 |

信息不足给中性分并在 evidence 写明「JD/画像未提供可比对信息」，严禁用常识补足。五维加权（34%/28%/14%/8%/6%）只参与总分在档位内的微调，**不得改变档位**——与档位冲突时以四层整体裁决为准（唯一例外：技能维 ≤25 强制档位不高于谨慎）。

硬性条件（学历/经验年限/地点/求职类型）不满足记入 hardBlocks 且 score ≤35。

matchedEvidence 写 3-6 条「岗位要求 X — 简历具备 Y」的证据句（每条 ≤40 字），只写真实可核验的匹配点，按与岗位的相关度排序；禁止「沟通能力强」「学习能力强」等无证据泛词。

gaps 只列岗位明确要求、简历与画像均未涉及的实质技能或技术栈，每条格式「技能名：匹配说明」（技能名 ≤20 字、匹配说明 20-80 字），匹配说明用求职者看得懂的自然语言写清「岗位场景要求 + 简历缺口现状 + 一句补强建议」三要素（如「Linux：岗位要求 Linux 环境下部署与排障，简历/画像未体现相关经历，建议通过实操项目补齐并在简历如实描述」），禁止多条说明雷同、禁止空话；简历其实做过相关工作但未写清的（如做过 Kafka 项目但未出现「消息队列」）标为「表达缺口：技能名」；每条都须逐条核对简历原文（含项目/经历行里写过的能力）；同义/同族已覆盖不计缺口（简历写 Git 不列 GitHub/GitLab、写 FastAPI 不列 Flask/Django、写 TypeScript/React 不列 JavaScript）；非技能词（HR、bug、Demo、JD）不计缺口；若确实没有实质缺口就留空数组，严禁凑数。

严禁把招聘方在线/活跃状态或岗位发布时间当作匹配理由。

greeting 必须求职者第一人称（「您好，我想应聘贵公司的{岗位名}」开头），只引用简历事实，严禁招聘方口吻，不得承诺薪资、到岗时间、面试时间。
