# BossClaw 使用前必读

> 欢迎使用 BossClaw（v2.4.0）。开始前请花约 2 分钟读完本文：它是什么、首次怎么配置、投递要注意什么、遇到问题怎么办。关闭本文：点击弹窗外侧任意处即可。

## 一、它是什么

BossClaw 是**面向求职者的本地 AI 投递助手**（Windows 桌面应用）。在应用内即可完成：导入简历 → 生成职业画像 → 选择投递方向 → 岗位采集与 AI 匹配 → 投递沟通 → 跟踪进度的完整闭环，全程不占用你的浏览器。

| 项目 | 说明 |
| --- | --- |
| 形态 | 单窗口桌面应用，不是后台常驻程序；除你配置的定时任务外，不会在无人操作时主动外呼 |
| 数据 | 全部保存在本机，零后端依赖；AI 只调用**你自己配置**的 API Key |
| 平台 | 默认 BOSS 直聘；可在「设置 → 招聘平台」按需启用猎聘 / 智联 / 前程无忧 |
| 全自动入口 | 工作台「开始投递」、自动沟通页「开始批量沟通」、定时任务——均由你显式启动，随时可在界面停止 |

## 二、首次使用（按顺序完成一次初始化）

1. **设置求职条件与 AI**（「设置」页）：填城市、求职类型、经验、学历、薪资；填 AI API Key（OpenAI / DeepSeek / 通义 / 智谱 / 硅基流动 / 火山方舟或自定义 OpenAI 兼容端点）→ 点「测试 AI 连接」→ 保存。
   - 没有 Key 也能用：画像 / 匹配 / 草稿会自动降级为本地规则。
2. **导入简历**（「简历中心」页）：上传 PDF / DOCX / MD / TXT，本地解析后核对原文。`.doc` 旧格式请先用 Word / WPS 另存为 `.docx` 或 `.pdf`。
3. **生成并核对职业画像**：AI 生成后逐项检查定位、技能、项目、学历、城市、薪资；**删除任何不准确、无证据或夸大的内容**。至少保留 1 个主方向与 1 个岗位搜索词才能保存。
4. **确认投递方向**（「投递方向」页）：勾选想投的方向，可改搜索词、调优先级、新增自定义方向；**必须点「确认方向」**，未确认的方向不会建立任务。
5. **（可选）启用更多平台**（「设置 → 招聘平台」）：只投 BOSS 可跳过。需要猎聘 / 智联 / 前程无忧时逐平台勾选启用并登录（见 4.4），至少保留一个启用平台；平台优先级决定搜索与投递顺序。
6. **开始投递**（「工作台」页）：进岗位详情 → 点「加入任务」→ 中栏核对、批准 → 浏览器打开沟通 → 人工确认发送。熟练后可切「开始投递」全自动，或用「自动沟通」页批量沟通。

## 三、首次投递：先单条验收

首次使用全自动投递 / 自动沟通前，**只处理一个自己确认过的岗位**，并逐项确认：

- [ ] 打开的就是你选的岗位，沟通对象与岗位一致
- [ ] 招呼语只引用简历中的真实内容，未替用户承诺薪资 / 时间
- [ ] 聊天窗口里已出现完整的**已发送文字气泡**
- [ ] 任务状态被正确记录
- [ ] 未出现登录异常、安全验证或账号限制

> 任何一步无法确认都应停下查原因，不要连续重试。首次全自动成功投递一条后，系统会**强制暂停待你验收**，供你核对沟通对象、文字气泡与附件。

## 四、使用须知

### 4.1 后台运行与停止

- 从工作台切到其他页面**不会中断**运行：搜索采集、自动投递、自动沟通会在后台继续推进，无需停留在工作台等待。
- 想**真正停止**：回工作台关闭「开始投递」，或在自动沟通页点「停止」。
- 「定时任务」页配置的任务到点会自动触发（投递 / 搜索采集 / 本地备份），不受当前页面影响。
- 后台遇到验证码 / 风控等需人工核验的情况会**暂停等待处理**：请切回工作台查看右侧浏览器与消息。

### 4.2 红线（务必遵守）

- 未确认聊天**文字气泡**：不发附件、不计成功、不跳下一岗位。
- 沟通对象或会话**明确冲突**、以及**外部网申**岗位：跳过，不沟通。
- 同一任务重复重试会被锁定；触发过风控的岗位「重试」会被禁用。
- 招呼语只用**求职者口吻**、只引用简历真实事实；不承诺薪资、到岗 / 面试时间或不存在的经历。
- 人工确认模式必须由你确认后才发送。

### 4.3 出现这些情况立即停止

遇到验证码 / 安全验证、登录或频率受限、岗位 / 沟通对象无法确认、页面结构变化、发送结果无法确认等情况，应用会**自动暂停并交人工**，不会自动重试或换号，请及时到界面处理。

### 4.4 多平台速查（BOSS 默认，其余需自行启用）

| 平台 | 投递方式 | 成功依据 | 每日上限 |
| --- | --- | --- | --- |
| BOSS 直聘 | 工作台一键投递 + 自动沟通 | 文字气泡确认 | 120 |
| 猎聘 | 自动沟通（「聊一聊」） | 平台预设招呼语自动发送 | 120 |
| 智联招聘 | 自动沟通（投递简历） | 投递成功 | 100 |
| 前程无忧 | 自动沟通（投递简历） | 投递成功 | 120 |

- **登录分两处**：工作台内置浏览器登录（设置页「招聘平台」扫码）；自动沟通需在自动沟通页用 Camoufox 隐身引擎逐平台登录（Cookie 存本机）。猎聘 / 智联 / 前程无忧的采集与投递**只走自动沟通通道**。
- 猎聘需先在猎聘 App 内设置好预设招呼语；**AI 跟聊仅 BOSS 支持**，其余平台回复请在平台 App 人工跟进。
- 工作台「一键投递」只处理 BOSS 岗位；其余平台岗位由自动沟通批量引擎按队列投递。
- 平台接近每日上限会自动停止交人工；次日重置。

### 4.5 风控码速查

| 码 | 含义 | 处理 |
| --- | --- | --- |
| 31 | 登录失效 | 停止，重新登录 |
| 32 / 36 | 封禁 / 账户异常 | 停止，交人工 |
| 35 | 需安全验证 | 停止，人工完成验证 |
| 37 | 环境异常（疑似机器人） | 停止，交人工（隐身引擎可降低误判） |
| 38 | 环境异常未登录 | 停止，先登录 |
| 1006 | 限速 | 停止，等待冷却 |
| 5002–5004 | 服务端异常 | 停止，稍后重试 |

### 4.6 隐身引擎（自动沟通用，可选，默认关闭）

- 自动沟通是**真实浏览器自动化**：会唤起独立可见窗口、真实点击「立即沟通」、输入并发送，进行中请勿遮挡或关闭该窗口。
- 它**只能使用 Camoufox 隐身内核**：系统 Chrome / Edge 不可复用（平台反爬会返回空壳页）。首次使用前安装：
  ```
  pip install "camoufox[geoip]"
  python -m camoufox fetch
  ```
- 内核缺失时自动沟通页会提示「引擎不可用」，请点「检测状态」或按上方命令安装。
- 隐身引擎需在设置页主动启用；它只降低「正常操作被误判为机器人」的概率，**不绕过**验证码 / 账户验证。
- CloakBrowser 隐身浏览器同为可选（工作台切换引擎）：首次启用自动下载约 200MB 内核；离线可手动下载后设置环境变量 `CLOAKBROWSER_BINARY_PATH` 指向本地文件。

### 4.7 数据与隐私

- 简历、画像、条件、Key、任务记录**默认只存本机**；备份与迁移用「设置 → 数据」的导出 / 导入。
- 登录态仅本地保存用于免重复登录，**不上传、不共享**。
- AI 会把必要的简历摘要与岗位信息发送给**你自己选择的**模型服务商，请按隐私要求选择模型。
- 反馈问题前请隐藏身份证、手机号、邮箱、API Key、聊天内容与账号信息。

### 4.8 免责声明

BossClaw 是独立开发的开源求职辅助工具，与任何招聘网站无隶属 / 合作 / 背书关系，不保证岗位信息真实性及任何投递、沟通、面试、录用结果。请仅操作本人有权使用的账号，自行核实岗位、公司与沟通内容，遵守相关网站服务协议，并对是否启用自动投递及由此产生的结果负责。

## 五、常见问题

| 问题 | 处理 |
| --- | --- |
| 启动后白屏 | 重启应用；仍复现时用 `start-bossclaw.cmd --visible` 启动并反馈日志 |
| 登录态丢失 | 在内置浏览器重新扫码登录一次，之后本地持久化 |
| AI 功能不可用 | 「设置」页检查 Key 已填写且「测试 AI 连接」通过；无 Key 时走本地规则 |
| 岗位无法「加入任务」 | 确认已登录，并**先进入岗位详情页**再点「加入任务」（列表页不支持） |
| 投递 / 沟通没发送成功 | 以聊天窗口**已发送文字气泡**为准：招呼语非空、对象与岗位一致、无验证码 / 风控 |
| 隐身引擎提示不可用 | 按 4.6 安装内核后，回自动沟通页点「检测状态」 |
| CloakBrowser 下载慢 / 失败 | 手动下载后设 `CLOAKBROWSER_BINARY_PATH` 指向本地文件 |
| `.doc` 简历无法解析 | 另存为 `.docx` / `.pdf` 后重新导入 |
| 数据备份 / 迁移 | 「设置 → 数据」导出 JSON 备份，导入即可恢复 |
| 其他问题 | 先查下方 Wiki，再提 [Issue](https://github.com/YanQuan-dozzy/Boss-Claw/issues)，附版本与操作步骤，并隐藏隐私信息 |
