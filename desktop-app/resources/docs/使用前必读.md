# BossClaw 使用前必读

> 欢迎使用 BossClaw（v2.5.5）。本文约 1 分钟读完，只讲三件事：怎么配置、投递要注意什么、遇到问题怎么办。**关闭本文：点击弹窗外侧任意处即可。**

## 它是什么

**本地 AI 投递助手**：导入简历 → 生成职业画像 → 选投递方向 → 采集并 AI 匹配岗位 → 投递沟通 → 跟踪进度，全程不占用你的浏览器。

- 数据**只存本机**，AI 只调用**你自己配置**的 Key。
- 不是后台常驻程序：除你配置的**定时任务**外，不会在无人操作时主动外呼。
- 默认投 BOSS 直聘；可在「设置 → 招聘平台」按需启用猎聘 / 智联 / 前程无忧。

## 首次使用（按顺序）

1. **设置页**：填求职条件（城市 / 类型 / 经验 / 学历 / 薪资）+ AI API Key → 点「测试 AI 连接」→ 保存。没有 Key 也能用，会自动降级为本地规则。
2. **简历中心**：上传 PDF / DOCX / MD / TXT，本地解析后核对原文。`.doc` 旧格式请先另存为 `.docx` / `.pdf`。
3. **核对职业画像**：逐项检查，**删除任何不准确、无证据或夸大的内容**；至少保留 1 个主方向 + 1 个搜索词才能保存。
4. **投递方向**：勾选想投的方向 → **点「确认方向」**（未确认不会建立任务）。
5. （可选）**启用更多平台**：只投 BOSS 可跳过；多平台的采集与投递走「自动沟通」（需先安装 Camoufox 内核，见下方「排障」）。
6. **工作台**：进岗位详情页 → 点「加入任务」→ 中栏核对、批准 → 人工确认发送。熟练后可开「开始投递」全自动，或用「自动沟通」批量。

## 首次投递：先单条验收

首次全自动前，**先只投一个你自己确认过的岗位**，确认：打开的就是所选岗位、招呼语基于真实简历、聊天窗出现完整**已发送文字气泡**、状态记录正确、无登录 / 验证码异常。

> 任何一步没把握就停下查原因，不要连续重试。系统首次全自动投递成功后**强制暂停待你验收**，供你核对沟通对象、气泡与附件。

## 必守红线

- 未确认**文字气泡**：不发附件、不计成功、不跳下一岗位。
- 沟通对象冲突或**外部网申**岗位：跳过，不沟通。
- 招呼语只用**求职者口吻**、只引真实简历；不承诺薪资、到岗 / 面试时间。
- 遇到验证码 / 风控 / 对象不确定：应用**自动暂停交人工，不自动重试、不换号**；切回工作台查看右侧浏览器处理。
- 切换页面**不会中断**投递；要真正停止请回工作台关闭「开始投递」。

### 多平台速查（可选，默认 BOSS）

- 工作台「一键投递」只处理 BOSS；猎聘 / 智联 / 前程无忧的采集与投递走「自动沟通」批量引擎。
- 猎聘需先在猎聘 App 内设置好预设招呼语；**AI 跟聊仅 BOSS 支持**，其余平台回复请在平台 App 人工跟进。
- 各平台独立每日上限：BOSS / 猎聘 / 前程无忧 120，智联 100；接近上限自动停止、次日重置。
- 自动沟通是真实浏览器操作，会唤起独立可见窗口，进行中请勿遮挡 / 关闭该窗口。

### 风控码速查（应用停下时对一下）

| 码 | 含义 | 处理 |
| --- | --- | --- |
| 31 | 登录失效 | 停止，重新登录 |
| 32 / 36 | 封禁 / 账户异常 | 停止，交人工 |
| 35 | 需安全验证 | 停止，人工完成验证 |
| 37 | 环境异常（疑似机器人） | 停止，交人工（隐身引擎可降低误判） |
| 38 | 环境异常未登录 | 停止，先登录 |
| 1006 | 限速 | 停止，等待冷却 |
| 5002–5004 | 服务端异常 | 停止，稍后重试 |

## 数据与隐私

数据（简历 / 画像 / 条件 / Key / 任务）默认只存本机；登录态仅本地保存用于免重复登录，不上传。AI 会把必要的简历摘要与岗位信息发送给**你自己选择的**模型服务商。反馈问题前请隐藏身份证、手机号、邮箱、API Key、聊天与账号信息。

## 常见问题（先看这里再提 Issue）

| 现象 | 处理 |
| --- | --- |
| 启动白屏 | 重启；仍复现用 `start-bossclaw.cmd --visible` 启动并反馈日志 |
| AI 不可用 | 设置页确认 Key 已填且「测试连接」通过；无 Key 走本地规则 |
| 无法「加入任务」 | 确认已登录，并**先进入岗位详情页**（列表页不支持） |
| 发送没成功 | 以已发送文字气泡为准，检查招呼语非空 / 对象一致 / 是否被风控 |
| 自动沟通提示引擎不可用 | 需安装 Camoufox 内核：`pip install "camoufox[geoip]"` 后 `python -m camoufox fetch` |
| `.doc` 简历无法解析 | 另存为 `.docx` / `.pdf` 重新导入 |
| 其他问题 | 详见下方 Wiki；提 Issue 时附版本 + 操作步骤并隐藏隐私 |
