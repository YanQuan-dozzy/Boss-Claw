# BossClaw 桌面版 v2.0.0

面向求职者的**本地 AI 投递助手**（Electron + React 桌面应用）。从简历解析、职业画像和岗位方向选择，到岗位信息整理、AI 匹配排序、沟通草稿生成与投递进度管理，集中在一个本地桌面应用中完成。数据本地优先，AI 密钥仅保存在用户本机。

## 本版亮点

- **内置浏览器 + 收集投递沟通模块从零重建**：工作台三栏（侧栏 + 消息进度 + 内置浏览器），手动 / 半自动投递闭环
- **自动沟通引擎重构**：可选真实浏览器引擎（Camoufox），自动打开沟通窗口、输入并发送打招呼语，支持发送在线简历；发送结果确认后才计成功
- **UI 组件体系完善**：状态徽章、日志控制台、指标卡片、聊天日志面板、反馈组件等
- **简历解析**：PDF / DOCX / TXT 本地解析（渲染进程内完成），职业画像 AI 生成 + 本地规则三级降级
- **AI 匹配与排序**：岗位匹配评分 / 决策 / 硬条件拦截 / 沟通草稿；综合匹配度、HR 活跃度、地点、薪资、新鲜度排序
- **任务进度管理**：任务级进度条 + 阶段标签 + 实时日志流，失败可重试 / 忽略 / 继续
- **可选隐身增强（默认关闭）**：Camoufox / CloakBrowser，仅降低正常操作被误判为机器人的概率，不绕过验证码与账户验证
- **主题**：浅色 / 深色 / 跟随系统

## 安装

- **系统要求**：Windows 10/11（x64）
- **安装版**：下载 `BossClaw-2.0.0-win-x64-setup.exe`，双击安装后从开始菜单启动
- **便携版**：下载 `BossClaw 桌面版-2.0.0-portable.exe`，解压即用，无需安装

> 首次启动按提示在「设置」页填写求职条件与 AI API Key 即可使用（API Key 仅保存在本机，不会上传）。

## 安全与使用边界

BossClaw 不绕过验证码、不突破任何平台限制、不自动换号。遇到安全验证、登录异常或结果无法确认时立即暂停交人工处理。使用请遵守目标网站规则与账号使用要求。
