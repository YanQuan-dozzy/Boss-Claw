## 一、这是什么

BossClaw 是**面向求职者的本地 AI 投递助手**（Electron 桌面应用）：独立运行、不占用你的浏览器；在应用内完成 **导入简历 → AI 生成职业画像 → 选择投递方向 → 整理岗位信息 → AI 匹配与排序 → 人工确认 / 半自动辅助 → 查看进度与处理异常** 的完整投递闭环。

| 项目 | 说明 |
| --- | --- |
| 形态 | 单窗口桌面应用（Electron + React），**不是后台常驻的 agent 程序**（见 4.2 节） |
| 数据 | 本地优先（localStorage），零后端依赖；AI 只调用**你自己配置**的 API Key |
| 内置浏览器 | 默认加载 BOSS 直聘，登录态本地持久化，免重复登录 |
| 当前版本 | v2.x（桌面版，Windows 10/11 x64） |

## 二、首次使用：配置清单

按以下顺序完成一次完整的初始化：

1. **设置求职条件与 AI**（「设置」页）：填写城市、求职类型、经验、学历、薪资条件；填写自己的 AI API Key（预设 OpenAI / DeepSeek / 通义千问 / 智谱 GLM / 硅基流动 / 火山方舟，或自定义 OpenAI 兼容端点）→ 点「测试 AI 连接」→ 保存。
   - 没有 Key 也能用，但职业画像 / AI 匹配 / 沟通草稿会降级为本地规则。
2. **导入简历**（「简历中心」页）：上传 PDF / DOCX / TXT，本地解析后核对原文；`.doc` 旧格式请先用 Word / WPS 另存为 `.docx` 或 `.pdf`。
3. **生成并检查职业画像**：AI 生成后逐项核对个人定位、技能、项目、学历、城市、薪资；**删除任何不准确、无证据或夸大的内容**，全部字段可编辑并保存（至少需要 1 个主方向 + 1 个搜索词）。
4. **选择投递方向**（「投递方向」页）：勾选准备投递的岗位方向，可修改搜索词、调整优先级、新增自定义方向；**必须点击「确认方向」**，系统只为明确勾选并保存的方向建立任务。
5. **选择执行模式**（「工作台」页）：
   - **人工确认（半自动）**：AI 完成分析和草稿后，逐条检查、修改、决定是否继续（首次使用推荐）
   - **半自动投递**：中栏批准岗位 → 浏览器跳转 → AI 草稿预填沟通框 → **用户点发送**
   - **自动辅助（全自动投递）**：按匹配优先级依次投递 `approved_queue` 队列，失败自动暂停交人工核对
   - **自动沟通**：按匹配优先级依次处理队列岗位，真实浏览器打开沟通窗口、输入并发送打招呼语

## 三、首次投递：单条验收（重要）

首次使用半自动 / 自动辅助时，**只处理一个由自己确认的岗位**，并逐项确认：

- [ ] 当前打开的是用户选择的岗位
- [ ] 当前沟通对象与岗位信息一致
- [ ] 沟通文字基于真实简历且内容准确
- [ ] 页面中确实出现了完整的已发送文字气泡
- [ ] 附件只在用户已配置且发送结果可确认时处理
- [ ] 任务状态被正确记录
- [ ] 没有出现登录异常、安全验证或账号限制

> **任何一步无法确认，都应立即暂停并查看原因，不要连续重复执行。** 首次成功投递一条后，系统会**强制暂停待验收**，供你核对沟通 HR、文字气泡与附件。

## 四、投递前必须遵守的规则

### 4.1 工作台切换其他模块后保持后台运行（重点）

**工作台是常驻宿主**：切换到侧栏任一其他页面（首页 / 简历中心 / 投递方向 / 任务进度 / 定时任务 / 数据统计 / 定制简历 / OpenClaw / 自动沟通 / 设置）时，工作台只是被隐藏（保持挂载），**不会停止运行**。内置浏览器、搜索采集、自动投递、自动沟通都会在后台继续推进；「自动沟通」引擎为模块级单例，跨页持久运行，工作台新批准（approved）的岗位会自动进入沟通队列。

- 切换页面**不会**中断工作台的自动辅助 / 投递流程，无需停留在工作台页面等待。
- 如需**真正停止**投递 / 沟通：请切回工作台（关闭「开始投递」）或在「自动沟通」页点击「停止」，而不是依赖切换页面。
- 后台运行期间内置浏览器不可见；遇到验证码 / 风控 / 对象不确定等需人工核验的场景，流程会**暂停等待人工处理**——请及时切回工作台查看右侧浏览器与消息气泡。
- 定时任务（「定时任务」页配置）不受页面影响，到设定时刻会自动触发投递 / 搜索采集 / 本地备份，请知悉此后台行为。

### 4.2 不是 agent 项目，但投递需确认

BossClaw 是**单窗口桌面应用**，不是后台常驻 / 常听的 agent 程序。**没有后台代理**：不存在独立于界面的 agent 在后台持续运行；所有能力都由你在界面里操作触发。自动投递 / 自动沟通启动后是模块级后台引擎跨页运行（见 4.1），但它由你显式启动 / 停止，不构成自主代理。**不做主动外呼（定时任务除外）**：除你预先配置的「定时任务」外，不会在无界面操作的情况下主动发起投递、发送消息或检索。

> AI / 技能（skill）调用只是规范的提示词约束，把明确指令注入 LLM 请求让模型按约束输出；它不会脱离你的界面自动执行浏览器操作、发送消息或检索。

**投递需在你确认后执行**：默认走人工 / 半自动确认，聊天对象、文字气泡与附件需你核对后再发送；**首次全自动成功投递一条后必须暂停验收**。

### 4.3 安全不变量（红线）

- 未确认右侧聊天**文字气泡**时：**不发送附件、不计成功、不跳下一岗位**。
- 目标 HR 或会话**明确冲突**时：不发送。
- **外部网申**岗位：跳过（优先级 -6000），不自动沟通。
- 同一任务**重复重试**会被锁定；触发过风控的岗位「重试」被禁用。
- **不得替用户承诺**薪资、到岗时间、面试时间或不存在的经历。
- 所有提示词与招呼语**必须使用求职者口吻，仅引用真实简历事实**。
- 人工确认模式：必须由用户确认后发送。

### 4.4 出现以下情况应立即停止

- 验证码、安全验证或账号异常提示
- 登录受限、访问受限或操作频率限制
- 当前岗位、公司或沟通对象无法确认
- 页面结构发生变化，执行目标不明确
- 沟通内容或附件的发送结果无法确认
- 用户未明确选择当前岗位或未授权本次操作

> 以上情况应用会**自动暂停并交人工处理**，不会自动重试、自动换号，请你及时查看界面处理。

### 4.5 风控码速查

| 风控码 | 含义 | 处理 |
| --- | --- | --- |
| 31 | 登录失效 | 停止，重新登录 |
| 32 | 封禁 | 停止，交人工 |
| 35 | 需安全验证 | 停止，人工完成验证 |
| 36 | 账户异常 | 停止，交人工 |
| 37 | 环境异常（疑似机器人） | 停止，交人工（可用隐身引擎降低误判，见 4.7） |
| 38 | 环境异常未登录 | 停止，先登录 |
| 1006 | 限速 | 停止，等待冷却 |
| 5002–5004 | 服务端异常 | 停止，稍后重试 |

### 4.6 提示词统一

- **打招呼语和求职信提示词统一使用工作台定制的提示词**；简历中心旧提示词已废弃，不要再使用或恢复。
- **提示词来源优先级**（打招呼语 / 求职信）：① skill（greetings 技能，含用户自定义技能）→ ② 简历中心「打招呼语提示词」输入框内容 → ③ 本地规则。仅当 greetings 技能被停用 / 无自定义技能时，输入框内容才会作为提示词使用。
- 定制简历的求职信生成同样复用工作台提示词与 `analyzeJob` 分析链路。

### 4.7 内置浏览器与隐身引擎（可选增强，默认关闭）

- **内置浏览器**默认加载 BOSS 直聘，登录态本地持久化；地址栏、调整侧栏后浏览器会联动，显示异常可切换页面再切回触发重绘。
- **自动沟通只能使用 Camoufox 原生隐身内核**：系统 Chrome / Edge 等本地浏览器**不可复用**（BOSS 反爬会对 Playwright 驱动的系统浏览器返回空壳页）。首次使用前需自行安装：
  `pip install "camoufox[geoip]"`（一次性）→ `python -m camoufox fetch`（下载指纹内核）。
- 检测不到内核时，「自动沟通」页会提示「隐身引擎当前不可用」，此时无法开始批量 / 单条沟通。
- 隐身引擎 / 隐身搜索（工作台「隐身搜索」）在设置页**默认关闭**，需用户主动启用；它只降低「正常操作被误判为机器人（code 37）」的概率，**不绕过**验证码 / 账户验证（code 35 / 36 / 32 仍立即停止交人工）。
- CloakBrowser 隐身浏览器同为可选增强（默认关闭）：首次启用自动下载约 200MB 隐身 Chromium 到 `~/.cloakbrowser/`；离线环境可手动下载后设置环境变量 `CLOAKBROWSER_BINARY_PATH` 指向本地二进制。
- 自动沟通走的是**真正的浏览器操作**（唤起独立可见窗口、真实点击「立即沟通」、真实输入并发送），进行中**请勿遮挡 / 关闭浏览器窗口**。

### 4.8 数据与隐私

- 简历、职业画像、筛选条件、API Key 和任务记录**默认保存在本机**（localStorage）；可通过「设置 → 数据」导出 / 导入 / 清空。
- BOSS 登录态持久化到本地，仅用于免重复登录，**不上传**；不导出、不共享、不远程托管 Cookie / Token / Session。
- AI 功能可能将必要的**简历摘要和岗位信息**发送给你**自行配置**的模型服务商，请根据隐私要求选择模型服务。
- **请勿把真实简历、API Key、手机号、邮箱、身份证信息或完整运行日志提交到公开仓库和 Issue**；导出诊断信息前先隐藏个人身份、联系方式、聊天内容、账号信息和密钥。

### 4.9 免责声明

BossClaw 是独立开发的开源求职辅助项目，与任何招聘网站、招聘服务商均不存在隶属、合作、代理、授权或背书关系。项目不保证第三方岗位信息的真实性、准确性或任何投递 / 沟通 / 面试 / 录用结果。用户应当：仅操作本人有权使用的账号与数据；自行核实岗位、公司、联系人和沟通内容；遵守适用法律、网站服务协议和账号使用要求；对是否启用自动辅助、是否发送内容及由此产生的账号和求职结果负责。

## 五、常见问题速查

| 问题 | 处理 |
| --- | --- |
| 启动白屏 | 设 `set BOSSCLAW_DEBUG=1` 后用 `start-bossclaw.cmd --visible` 启动，看 `userData/debug-render.log` |
| 登录态丢失需重新扫码 | v3 重建后首次启动会清空旧会话，重新扫码登录一次，之后本地持久化 |
| AI 功能不可用 | 检查「设置」页是否填写并**测试通过** AI API Key；无 Key 时降级为本地规则提示 |
| 岗位无法「加入任务」 | 确认内置浏览器已登录 BOSS；**先进入岗位详情页**再点「加入任务」（列表页不支持） |
| 自动沟通 / 自动辅助没发送成功 | 以右侧聊天**文字气泡确认**为准：打招呼语非空、沟通对象与岗位一致、未出现验证码 / 安全验证 |
| 隐身引擎提示「未检测到可用内核」 | 安装本地浏览器，或执行 `pip install 'camoufox[geoip]' && python -m camoufox fetch` 下载指纹内核 |
| CloakBrowser 下载慢 / 失败 | 手动下载 `.zip` 后设 `CLOAKBROWSER_BINARY_PATH` 指向本地二进制 |
| `.doc` 简历无法解析 | 用 Word / WPS 另存为 `.docx` 或 `.pdf` 后再导入 |
| 数据备份 / 迁移 | 「设置 → 数据」导出 JSON 备份；导入恢复 |
| 如何反馈问题 | 先查本必读与 Wiki，再提交 [Issue](https://github.com/YanQuan-dozzy/Boss-Claw/issues)，附版本、系统、出错步骤，**隐藏隐私信息后**再截图 |
