# BossClaw 桌面版 v2.3.0

面向求职者的**本地 AI 投递助手**（Electron + React 桌面应用）。从简历解析、职业画像和岗位方向选择，到岗位信息整理、AI 匹配排序、沟通草稿生成与投递进度管理，集中在一个本地桌面应用中完成。数据本地优先，AI 密钥仅保存在用户本机。

## 本版亮点

- **批量自动沟通引擎重构**：按匹配优先级批量处理沟通队列；严格遵循关键安全不变量——未确认文字气泡不发送附件、第一次全自动成功后必须暂停验收、招呼语非空校验、外部网申跳过、重复重试锁定等，异常即停交人工处理
- **通信模块实现优化**：聊天往返、投递锁与会话投递去重逻辑收敛，降低重复投递与越位操作风险
- **隐身引擎 / 隐身浏览器优化**：Camoufox / CloakBrowser 可选增强细节完善，产物目录与应用结构同步更新（当前默认关闭，需在设置页主动启用）
- **工程与发布**：版本升至 2.3.0；Windows 安装包（NSIS）+ 便携版重新产出并发布

## 安装

- **系统要求**：Windows 10/11（x64）
- **安装版**：下载 `BossClaw-2.3.0-x64.exe`，双击安装后从开始菜单启动
- **便携版**：下载 `BossClaw-2.3.0-portable.exe`，解压即用，无需安装
- macOS（dmg/zip）与 Linux（AppImage/deb）产物沿用 v2.1.0，或从当前源码自建

> 首次启动按提示在「设置」页填写求职条件与 AI API Key 即可使用（API Key 仅保存在本机，不会上传）。

## 安全与使用边界

BossClaw 不绕过验证码、不突破任何平台限制、不自动换号。遇到安全验证、登录异常或结果无法确认时立即暂停交人工处理。使用请遵守目标网站规则与账号使用要求。
