HTTP 状态 ≠ 业务成败：未登录（31）、需人工验证（35）、风控（36/32）等业务失败均以 HTTP 200 + {ok:false, code, message} 返回。完整 code 表见 Camoufox 面板各端点与 YAML。
三条「接口面」 A. 主窗口 IPC：渲染层 ⇄ 主进程，入口 window.electron.*（invoke=Promise 请求/响应；send=单向命令；on=订阅事件，返回取消函数）。
B. BOSS 页面桥：<webview> host ⇄ guest（webview.cjs 注入，标记 window.__bossclawPreload）。
C. CloakBrowser 页面桥：launcher ⇄ Page（cloakPreload.cjs，window.__bossclaw_dispatch / listen / emit）。
网络与鉴权 两个 HTTP 服务仅监听 127.0.0.1，令牌为代码内静态常量（本地回环信任模型）。请勿改为监听 0.0.0.0 或暴露到局域网。主窗口采用 contextIsolation:true + nodeIntegration:false，渲染层仅能调用 preload 白名单 API。
与招聘平台交互的安全红线（AGENTS.md §2.1） code 36 / 32 风控 → 立即停止 code 35 安全验证 → 转人工，绝不自动重试 不绕过验证码 / 账户验证 招呼语非空且 ≤800 字 每日配额与发送限速由渲染层控制 未确认文字气泡不计成功（code 501 需人工核对）
自动沟通仅降低「正常操作被误判为机器人（code 37）」的概率，不提供任何绕过平台安全措施的路径。
