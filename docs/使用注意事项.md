# Boss-claw 使用注意事项

> 说明：**首次使用请先阅读 [使用前必读](./使用前必读.md)**（融合了本文档与 Wiki 快速开始 / 安全合规 / FAQ 的核心要点）。本文档汇总使用 Boss-claw 桌面版时需要特别留意的点。重点阅读第 1、2 节，其余为通用注意事项。

***

## 1. 重点：工作台切换其他模块后保持后台运行

**工作台是常驻宿主：切换到侧栏任一其他页面（首页 / 简历中心 / 投递方向 / 任务进度 / 定时任务 / 数据统计 / 定制简历 / OpenClaw / 自动沟通 / 设置）时，工作台只是被隐藏（CSS visibility/opacity 降级，保持挂载），不会停止运行。** 内置浏览器（webview）、搜索采集、自动投递、自动沟通均会**在后台继续推进**；「自动沟通」引擎为模块级单例，跨页持久运行，工作台新批准（approved）的岗位会自动进入沟通队列。

### 规则

* 切换页面**不会**中断工作台的自动辅助 / 投递流程，无需停留在工作台页面等待。

* 如需**真正停止**投递 / 沟通：请切回工作台（关闭「开始投递」）或在「自动沟通」页点击「停止」，而不是依赖切换页面。

* 后台运行期间内置浏览器不可见；遇到验证码 / 风控 / 对象不确定等需人工核验的场景，流程会**暂停等待人工处理**——请及时切回工作台查看右侧浏览器与消息气泡。

* 定时任务（「定时任务」页配置）不受页面影响，到设定时刻会自动触发投递 / 搜索采集 / 本地备份，请知悉此后台行为。

***

## 2. 本项目不是 agent 项目

Boss-claw 是**单窗口的桌面应用（Electron + React）**，不是后台常驻 / 常听的智能体（agent）程序。

> 补充：本项目也会用到 **AI / 技能（skill）调用**，但它与「agent 自主运行」是两回事。**skill 调用只是规范的提示词（Prompt / system prompt）约束**——即把明确的、限定的指令文本注入到 LLM 请求中，让模型按约束输出；它不会脱离你的界面自动去执行浏览器操作、发送消息或检索。因此 skill 调用不改变本项目「非 agent」的性质，也不代表存在后台自主代理在替你做事。

### 影响

* **没有后台代理**：不存在独立于界面的 agent 在后台持续运行；所有能力都由你在界面里操作触发。自动投递 / 自动沟通启动后是**模块级后台引擎跨页运行**（见第 1 节），但它由你显式启动 / 停止，不构成自主代理，不改变本项目「非 agent」的性质。

* **不做主动外呼（定时任务除外）**：除你预先配置的「定时任务」（到点自动触发投递 / 搜索采集 / 本地备份）外，不会在无界面操作的情况下主动发起投递、发送消息或检索。

* **投递需在你确认后执行**：默认走人工 / 半自动确认，聊天对象、文字气泡与附件需你核对后再发送；首次全自动成功投递一条后必须暂停验收。

* **不会替你兜底**：验证码 / 安全验证 / 对象不确定 / 发送未确认等场景都会立即暂停并交回人工处理，请你及时查看界面并处理。

***

## 3. 其他使用注意事项

### 3.1 投递与安全

* 未确认右侧聊天**文字气泡**时：不发送附件、不计数成功、不跳转下一岗位。

* 目标 HR 或会话**明确冲突**时不发送。

* **外部网申**岗位会被跳过（优先级 -6000）。

* 同一任务重复重试会被锁定。

* 不替用户承诺薪资、到岗时间、面试时间或不存在的经历。

* 所有提示词与招呼语**必须使用求职者口吻，仅引用真实简历事实**。

### 3.1.1 多平台（猎聘 / 智联招聘 / 前程无忧 51Job）使用须知

Boss-claw 在 BOSS 直聘基础上支持多平台搜索、采集与投递（平台口径来自 get_jobs / Auto-JobHunter 开源实现，统一收口于 `platforms.ts`）：

* **启用与优先级**：设置页 →「招聘平台」分区，逐平台勾选启用（BOSS 直聘**同样可取消勾选**，与其余平台一致）；系统要求**至少保留一个启用平台**，唯一启用平台不可取消。启用后「工作台」搜索栏与内置浏览器「新标签页」可选对应平台；平台优先级（1 = 最高）决定工作台搜索顺序与自动沟通执行顺序（先完成高优先级平台全部任务再切下一平台）。
* **登录（两个通道，各自独立持久化）**：
  * **工作台（内置浏览器）通道**：设置页「招聘平台」卡片点「扫码登录」→ 工作台内置浏览器新标签打开该平台登录页，扫码 / 账号登录后由 Electron 分区会话持久化，免重复登录；对应卡片「退出」清除该分区会话。
  * **自动沟通（Camoufox 隐身）通道**：在「自动沟通」页各平台卡片逐平台「登录 / 退出」；Cookie 按平台独立持久化 `~/.bossclaw/camoufox-cookies-{platform}.json`（BOSS 保持旧路径 `camoufox-cookies.json`）。
  * 投递 / 采集前须确保**对应通道**已登录：非 BOSS 平台的搜索采集与投递走 Camoufox 通道，需在「自动沟通」页完成该平台 Camoufox 登录。
* **采集通道限制**：工作台「搜索采集」多选平台后**串行采集**；BOSS 走内置浏览器可视化采集（启用 Camoufox 时可分流为隐身采集）；**猎聘 / 智联 / 前程无忧只能走 Camoufox 隐身采集**（webview 可视化采集为 BOSS 专属链路），未登录会提示先到「自动沟通」页登录。
* **投递语义（未确认不计成功）**：
  * BOSS：输入并发送打招呼语 → 以聊天窗**文字气泡确认**计成功。
  * 猎聘：点「聊一聊」→ 平台用 **App 预设招呼语自动发送** → 确认聊天窗打开 / 按钮变「继续聊」即计成功。**须先在猎聘 App 设置招呼语文案**（脚本不注入文本）。
  * 智联：点「投递」→ 确认「投递成功」弹层 / 按钮变「已投递」即计成功。
  * 前程无忧 51Job：按平台「投递 / 批量投递」操作 → 以平台返回的成功数量 / 按钮状态确认计成功。
* **投递入口**：工作台「一键投递」**仅处理 BOSS 直聘岗位**；猎聘 / 智联 / 前程无忧岗位确认后停留在投递队列，由「自动沟通」批量引擎（Camoufox）投递。
* **每日配额与上限（各平台独立）**：设置页「招聘平台」逐平台配置「每日投递目标」——BOSS / 猎聘 / 前程无忧默认 **120/日**，智联默认 **100/日**（贴合其平台侧约 100 次/日上限），0 = 不限；实际上限取 min(平台每日目标, 平台侧上限, 全局安全上限 150)，智联最多 100/日，接近上限自动停止交人工；各平台每日计数互不挤占。
* **AI 跟聊（needsReply）仅 BOSS 聊天链路支持**；其余平台投递完成后回复请在平台 App 内人工跟进。
* 外部网申 / 第三方外链岗位在各平台同样按「外部网申」规则跳过（按平台按钮文案识别）。
* 所有平台同样遵守：未确认不计成功、首次投递后强制暂停验收、code 35 / 36 / 32 / 37 立即停止交人工、不绕过验证码 / 账户验证、不自动重试 / 换号。


### 3.2 提示词统一

* **打招呼语和求职信提示词统一使用工作台定制的提示词**；简历中心旧提示词已废弃，不要再使用或恢复。

* **提示词来源优先级**（打招呼语 / 求职信）：① skill（greetings 技能，含用户自定义技能）→ ② 简历中心「打招呼语提示词」输入框内容 → ③ 本地规则。**仅当 greetings 技能被停用 / 无自定义技能时**，输入框内容才会作为提示词使用。输入框修改后点击「保存提示词」即保存；留空或恢复默认表示不覆盖（沿用技能或系统默认）。

* 定制简历的求职信生成同样复用工作台提示词（`buildTailorSystemPrompt(greetingInstructions)`），并复用工作台 `analyzeJob` 分析链路（不写入共享 `greetings` 列表）。

* 设置页 AI 配置中已移除「打招呼语（greetings）」技能项，因其已无注入点，请勿再加入。

### 3.3 内置浏览器（webview）

* 内置浏览器默认加载 BOSS 直聘；启用多平台后，「新标签页」下拉可选猎聘 / 智联招聘 / 前程无忧首页。各平台登录态由 Electron 分区会话按平台持久化（设置页「招聘平台」扫码登录即在工作台打开对应登录页）。

* 地址栏、调整侧栏后浏览器会随之联动；若显示异常请切换页面再切回触发重绘。

* 浏览器区域的布局依赖 Electron `<webview>` 的 Flex 伸缩机制，**不要对其设置** **`display: block`** **等破坏 Flex 布局的样式**（否则高度会缩死为 150px 或页面截断）。

### 3.4 自动沟通（多平台，只能使用 Camoufox 原生内核，需自行下载）

* **「自动沟通」页只能使用 Camoufox 原生隐身内核**。系统 Chrome / Edge 等本地浏览器**不可复用**（招聘平台反爬会对 Playwright 驱动的系统浏览器返回空壳页，无法正常加载 / 沟通），所以该功能**必须安装 Camoufox 原生内核**。

* **内核需用户自行下载**（项目不自动下载、不兜底浏览器）。首次使用前需手动执行：
  `pip install "camoufox[geoip]"`（一次性）→ `python -m camoufox fetch`（下载指纹内核）。

* **多平台批量沟通**：BOSS（聊天打招呼，文字气泡确认）、猎聘（「聊一聊」，App 预设招呼语自动发送，须先在猎聘 App 设置招呼语）、智联 / 前程无忧（投递简历，成功确认）均经此引擎；按「设置 → 招聘平台」的平台优先级串行执行，各平台卡片独立「登录 / 退出」（Cookie 按平台独立持久化，见 3.1.1）。

* 检测不到内核时，「自动沟通」页会提示**「隐身引擎当前不可用 / 请安装 Camoufox 隐身引擎内核」，此时无法开始批量沟通或单条沟通**。

* 「自动沟通」走的是**真正的浏览器操作**：唤起独立可见窗口、真实点击沟通 / 投递按钮、真实键盘输入招呼语并发送、确认文字气泡 / 投递成功后计数成功。进行中**请勿遮挡 / 关闭浏览器窗口**。

* 自动沟通同样遵守安全不变量：先扫码登录（独立的 Camoufox 会话，登录态持久化到 `~/.bossclaw/camoufox-cookies*.json`）；code 35/36/32/37 等验证类情况立即停止交人工，**不绕过验证码 / 账户验证、不自动重试、不自动换号**。

### 3.5 隐身搜索（可选增强，默认关闭）

* Camoufox 隐身搜索 / 隐身采集（工作台「搜索采集」多选平台）同样走 Camoufox 引擎，可复用上面第 3.4 节的内核；**猎聘 / 智联 / 前程无忧平台的采集必须走此通道**（webview 可视化采集为 BOSS 专属链路），采集前对应平台须已在「自动沟通」页完成 Camoufox 登录。

### 3.6 AI 与配置

* AI 需在设置中配置真实 LLM（OpenAI / DeepSeek / 通义 / 智谱或自定义 OpenAI 兼容端点）并填入密钥后方可使用。

* 主进程相关改动（如桥接、IPC）需**重启应用**才能生效。

* 本地数据零后端依赖，状态（含主题、浅色/深色）保存在 localStorage。
