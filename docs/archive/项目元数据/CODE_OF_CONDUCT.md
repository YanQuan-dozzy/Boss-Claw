# Code of Conduct

Be respectful, factual, and privacy-conscious.

- Do not publish API keys, resumes, recruiter conversations, phone numbers, or other personal data.
- Do not use project spaces to harass job seekers, recruiters, maintainers, or contributors.
- Discuss technical disagreements with reproducible evidence.
- Do not request features intended to bypass verification, platform safeguards, or usage limits.

Maintainers may edit, hide, or remove content that violates these rules and may
restrict participation when necessary to protect users and the project.
