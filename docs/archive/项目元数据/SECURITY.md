# Security Policy

## Supported version

当前维护版本：`1.3.x`

## Reporting a vulnerability

不要在公开 Issue 中发布 API Key、真实简历、聊天记录、手机号、Cookie、身份证明或其他可识别个人身份的信息。

可通过以下方式联系：

- GitHub Security Advisory（推荐）
- GitHub Issue：只提交不含利用细节和隐私的概述

请提供版本、复现步骤、影响范围、是否可稳定复现，以及脱敏后的必要证据。维护者会优先处理可能导致密钥泄露、任意页面执行、错误聊天对象发送或本地桥接越权的问题。
