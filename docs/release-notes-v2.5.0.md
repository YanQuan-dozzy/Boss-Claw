# BossClaw 桌面版 v2.5.0

面向求职者的**本地 AI 投递助手**（Electron + React 桌面应用）。数据本地优先，AI 密钥仅保存在用户本机；自动沟通遵循关键安全不变量，异常即停交人工处理。

## 本版亮点

- **多平台投递适配**：Camoufox 隐身引擎由单一 BOSS 链路扩展为按平台细分（`platforums/job51` / `liepin` / `zhaopin`），「自动沟通」支持 BOSS 直聘文字气泡确认、猎聘「聊一聊」、智联招聘 / 前程无忧投递简历（投递成功确认）；按平台优先级串行处理，各平台独立登录态与每日计数
- **AI 跟聊计数修正**：HR 来消息后 AI 自动跟聊回复不再计入「单日投递上限」，避免跟聊占用正式投递名额（仅置 `sent` + 记录 `replySentAt`，不改写投递用 `sentAt`）
- **安全加固**：会话投递去重、投递锁、持久化安全（`persistSafe`）与多平台登录态隔离细节收敛，降低重复投递、越位操作与数据破坏风险
- **工程与发布**：版本升至 2.5.0；Windows 安装包（NSIS）+ 便携版重新产出并发布

> 多平台（猎聘 / 智联招聘 / 前程无忧）与隐身引擎均为**可选增强**，需在「设置」页主动启用并完成对应平台登录；BOSS 直聘链路与内置浏览器投递逻辑保持不变。

## 安装

- **系统要求**：Windows 10/11（x64）
- **安装版**：下载 `BossClaw-2.5.0-x64.exe`，双击安装后从开始菜单启动
- **便携版**：下载 `BossClaw-2.5.0-portable.exe`，解压即用，无需安装
- macOS（dmg/zip）与 Linux（AppImage/deb）产物沿用 v2.1.0，或从当前源码自建

> 首次启动按提示在「设置」页填写求职条件与 AI API Key 即可使用（API Key 仅保存在本机，不会上传）。

## 安全与使用边界

BossClaw 不绕过验证码、不突破任何平台限制、不自动换号。遇到安全验证、登录异常或结果无法确认时立即暂停交人工处理。使用请遵守目标网站规则与账号使用要求。
