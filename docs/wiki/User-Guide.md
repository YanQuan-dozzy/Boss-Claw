# 功能指南 · BossClaw 详细操作手册

本文是 BossClaw 的**完整上手操作手册**，按「界面总览 → 首次配置 → 简历 → 画像 → 投递方向 → 工作台投递 → 自动沟通 → 任务进度 → 统计 → 定制简历 → OpenClaw」的顺序，手把手教你怎么操作这个软件。文中所有按钮、标签文字均与软件界面一致。

---

## 一、界面总览

启动 BossClaw 后是一个单窗口桌面应用，分四个区域：

```
┌──────────────────────────────────────────────────────────────┐
│ ① 标题栏：BossClaw 桌面版 · 投递引擎状态 · 主题切换 · 窗口按钮  │
├──────────┬───────────────────────────────────────────────────┤
│ ② 侧栏   │  ③ 主内容区（工作台=三栏；其余页面=双栏）          │
│  (10入口) │                                                   │
├──────────┴───────────────────────────────────────────────────┤
│ ④ 状态栏：OpenClaw 状态 · BOSS 登录态 · 投递统计              │
└──────────────────────────────────────────────────────────────┘
```

### ① 标题栏
- 左侧：BossClaw 图标 +「BossClaw 桌面版」+ 状态灯 + 引擎文案（`投递引擎 · 运行中 / 已停止 / 未连接`）
- 右侧：主题切换胶囊按钮（**浅色 / 深色 / 跟随系统**）+ 最小化 / 最大化 / 关闭按钮
- 双击标题栏空白处可最大化 / 还原窗口

### ② 功能侧栏（10 个入口，从上到下）

| 顺序 | 入口 | 作用 |
| --- | --- | --- |
| 1 | 首页 | 运行状态概览、快捷入口、任务控制、最近动态 |
| 2 | 工作台 | **核心投递页（三栏）**：岗位队列 + 内置浏览器 |
| 3 | 简历中心 | 导入简历、AI 打招呼语提示词、职业画像 |
| 4 | 投递方向 | 勾选岗位方向、搜索词、优先级 |
| 5 | 任务进度 | 任务列表、异常任务失败恢复 |
| 6 | 数据统计 | 投递指标与可视化图表 |
| 7 | 定制简历 | 输入岗位 JD，生成定制摘要 / 量化经历 / 求职信 / 技能缺口 |
| 8 | OpenClaw | 本地桥接（OCR / 日报 / 日志） |
| 9 | 自动沟通 | 批量自动打招呼（真实浏览器引擎） |
| 10 | 设置 | 执行模式、求职条件、LLM、AI 技能、隐身引擎、数据管理 |

侧栏底部固定显示 `OpenClaw 已连接 / 未连接` 状态灯；侧栏可收起（点击「收起侧边栏」），折叠后悬停按钮可展开。

### ④ 状态栏
- 左侧：`OpenClaw 已连接/未连接`、`BOSS 已登录 / 未登录 / 检测中`
- 右侧：`已投递 N · 已跳过 N · 确认队列 N`（实时统计）

## 二、第一步：完成设置（所有功能的前提）

点击侧栏「**设置**」，从上到下依次检查 5 个分区：

### 2.1 常规与外观

| 设置项 | 说明 |
| --- | --- |
| 执行模式 | Segmented 切换：**人工确认（半自动）** / **全自动投递**。首次使用请选「人工确认」，熟悉后再切全自动 |
| 界面主题 | 浅色 / 深色 / 跟随系统 |
| 内置浏览器标签页管理 | 「自动关闭闲置标签页」开关 + 闲置关闭阈值（默认 5 分钟） |

### 2.2 求职偏好（过滤与投递条件的核心）

| 设置项 | 默认值 / 说明 |
| --- | --- |
| 目标城市 | 逗号分隔，如 `深圳,广州` |
| 薪资期望 | 如 `15k-25k` |
| 求职类型 | 不限 / 全职 / 实习 / 校招 / 兼职 |
| 学历要求 | 不限 / 大专 / 本科 / 硕士 / 博士 |
| 经验要求 | 按需填写 |
| **每日目标投递数**（dailyTarget） | 默认 **120**，建议分时段投递，避免触发风控 |
| **最低匹配要求分**（minScore） | 默认 **75**，低于此分的岗位不推荐 |
| HR 活跃度过滤 | 不限 / 本月活跃及以上 / 本周 / 3 日内 / 今日 / 刚刚活跃及以上 / 仅在线 |
| 面试方式筛选 | 不限 / 仅线上 / 仅线下 |
| 城市反选黑名单 | 排除省份 / 排除城市（勾选后自动跳过这些地区的岗位） |
| 公司 / 招聘方黑名单 | 命中即自动跳过 |
| 搜索采集范围控制 | 自动下拉加载、最大轮数（默认 12）、滚动间隔（默认 1500ms 滑块）、断点续采序号 |

> 这里的过滤条件会在「加入任务」入队时**自动生效**：HR 活跃度不达标、猎头岗位、城市被排除、公司命中黑名单、面试方式冲突的岗位会直接标记「已跳过」，并在日志中说明原因。

### 2.3 LLM 配置（AI 能力的前提）

| 设置项 | 说明 |
| --- | --- |
| 服务商预设 | 下拉选择：OpenAI / DeepSeek / 通义千问 / 智谱 GLM / 硅基流动 / 火山方舟 / **自定义（OpenAI 兼容）** |
| Base URL / 模型名称 / API Key | 按服务商填写；Key 只保存在本机 |
| 测试连接 | 填写后点击测试，通过后再保存 |
| AI 结果缓存 | 本机缓存（条数 / 命中 / 占用 KB +「清空缓存」）；服务端缓存（请求数 / 命中 tokens +「清零统计」） |

> **没有 AI Key 也能用吗？** 可以，但职业画像、AI 匹配、沟通草稿会降级为本地规则，建议配置一个 Key 以获得完整体验。

### 2.4 AI 技能（Skills 层）

| 设置项 | 说明 |
| --- | --- |
| 内置技能 | 4 个标准 SKILL.md 技能：`resume-profile`（简历画像）/ `job-analysis`（岗位分析）/ `greetings`（打招呼语）/ `tailor-cv`（定制简历），按任务作用域自动注入 AI 提示词 |
| 启用开关 | 每个技能可独立启停；关闭后对应 AI 调用的增强约束不再注入，开关变化会使相关 AI 缓存自动失效 |
| 导入 SKILL.md | 选择标准 SKILL.md 文件（frontmatter + 正文）导入为自定义技能 |
| 新建技能 | 弹窗表单：名称 + 绑定作用域 + 指令正文（注入 system prompt） |
| 自定义技能 | 保存在本机用户数据目录（`userData/skills`），可停用 / 删除（内置技能不可删除），带紫色「自定义」Tag |
| 恢复默认 | 一键恢复全部技能为默认启用 |

### 2.5 隐身引擎与桥接（可选，默认关闭）

| 设置项 | 说明 |
| --- | --- |
| 底座引擎 | Segmented：**WebView（默认）** / CloakBrowser / Camoufox |
| CloakBrowser 面板 | 「检测状态」「停止引擎」（首次启用自动下载约 200MB 隐身 Chromium） |
| Camoufox 面板 | 「检测状态」「停止桥」、指纹伪装系统（Windows 推荐 / macOS / Linux）、隐身搜索页数（1-5）、优先隐身通道、「隐身扫码登录」「退出登录」 |
| OpenClaw 本地桥接 | 「刷新状态」「前往 OpenClaw 管理页」 |

> 隐身引擎仅用于降低「正常操作被误判为机器人（环境异常 code 37）」的概率，**不绕过**验证码与账户验证（code 35 / 36 / 32 仍立即停止交人工）。

### 2.6 数据管理

- **导出 JSON 备份**：把全部本地数据（简历、画像、方向、任务、统计、设置）导出为 JSON 文件
- **导入 JSON 备份**：恢复之前的备份
- **清空全部数据**：危险操作，弹出确认 Modal（含不可恢复警告），清空后需重新配置

## 三、第二步：导入简历（简历中心）

1. 点击侧栏「**简历中心**」
2. 点击「**导入文件**」按钮（已有文本时变为「**重新导入**」），或把文件拖拽到拖拽区（提示：「点击或拖拽简历文件到此处」「100% 本地安全解析 · 单个文件 ≤ 10MB」）
3. 支持格式：**PDF / DOCX / TXT**（全部本地解析，不经过网络）；旧版 `.doc` 格式请先用 Word/WPS 另存为 `.docx` 或 `.pdf`
4. 解析成功后，原文显示在编辑区，可修改；点击「**保存原文**」保存

> 解析方法会以蓝色 Tag 标注（如 PDF 自研解析器 / mammoth 等）。

---

## 四、第三步：生成职业画像 + 打招呼语

仍在「简历中心」页，往下滚动：

### 4.1 AI 打招呼语提示词

- 8 行提示词编辑器，可「**生成预览**」「**保存提示词**」「**恢复默认**」「**清空预览**」
- 预览区展示 4 条打招呼语，每条可「**复制**」
- 界面注明：「请勿替用户承诺薪资、到岗或面试时间」

### 4.2 职业画像（可编辑草稿）

1. 点击「**生成职业画像**」——AI 生成初稿（失败自动降级到本地规则）
2. 核对并编辑以下字段：
   - **个人定位摘要**
   - **主方向**（最多 3 个）
   - **搜索关键词**（真实岗位名，最多 12 个）
   - **技能 / 城市 / 求职类型 / 学历 / 经验 / 薪资 / 排除方向**
3. 点击「**保存**」。保存校验：**画像至少需要一个主方向和至少一个搜索词**，否则无法保存

> 职业画像必须基于真实简历信息，删除任何夸大或不实的内容。

## 五、第四步：确认投递方向（投递方向）

1. 点击侧栏「**投递方向**」
2. 看到方向卡片列表，每张卡片包含：
   - 启用 Switch、名称、`自定义/画像` Tag、`#优先级`、删除按钮（需二次确认「删除投递方向」）
   - 「搜索词」输入框（输入后**回车添加**搜索关键词）
   - 匹配技能、能力缺口展示
   - 上下箭头调整优先级
3. 三种操作：
   - 「**根据画像更新**」：从职业画像重新生成方向
   - 「**新增自定义方向**」：弹窗填写（如：游戏前端开发）
   - 「**确认方向（N）**」：**必须点击确认**，系统只对已确认的方向建立任务；未确认会提示「请至少勾选一个投递方向」
4. 确认后显示绿色 Tag「已确认」

## 六、第五步：工作台投递（核心操作）

点击侧栏「**工作台**」，这是三栏布局：`[侧栏] │ [中栏：岗位进度+列表+日志] │ [右栏：内置浏览器]`。

### 6.1 用内置浏览器找岗位

1. 右栏浏览器默认打开 BOSS 直聘（`https://www.zhipin.com`）；首次使用需**登录**（登录态本地持久化，之后免登录）
2. 工具栏：后退 / 前进 / 刷新 / 在系统浏览器中打开 / 地址栏（前缀「链接」，回车跳转）/「**前往**」按钮
3. 搜索并打开**某个岗位的详情页**
4. 点击工具栏「**加入任务**」→ 岗位进入中栏「确认队列」

> ⚠️ 如果在**岗位列表页**点「加入任务」，会提示：「当前是岗位列表页（含多个岗位）。请点击具体岗位进入详情页后，再点『加入任务』加入单个岗位」。请先进详情页。

### 6.2 岗位进度卡（中栏顶部）

- **阶段条**：`整理 → 匹配 → 排序 → 沟通 → 投递` 五段
- **6 个统计块**：搜索中、确认队列、投递队列、投递中、已投递、失败
- 右上按钮「**搜索采集**」（启用隐身引擎时显示「**隐身采集**」；运行中变红「**停止采集**」）
- 采集中有实时进度条（N/M）与状态 Tag：准备中 / 滚动中 / 点击中 / 完成，以及「暂停/继续」
- 投递中的 active 卡片：显示岗位名、阶段进度 %、「**打开岗位**」「**暂停投递**」按钮

### 6.3 岗位列表（中栏中部）

- 筛选 Segmented：`全部 N / 待确认 N / 待投 N / 投递中 N / 已投 N / 失败 N`，可勾选「**显示已忽略/跳过**」
- 批量按钮：「**一键投递**」（有待投岗位才亮起）、「**批量确认**」、「**全部忽略**」
- 提示条：「待确认岗位按 AI 匹配分从高到低排列；确认沟通前可直接修改求职招呼语。」
- 每张岗位卡片显示：标题+薪资、公司/城市/薪资行、**AI 评分** chip、`#优先级`、决策文案（**推荐 / 谨慎 / 不推荐**）、`HR 在线` Tag、`线上面试/线下面试` Tag、状态 Tag
- 展开卡片可看到 AI 匹配理由 + 招呼语编辑框（placeholder：「请输入你希望发送给招聘方的求职招呼语」）

### 6.4 岗位状态与单条操作

| 状态 Tag | 含义 | 可用的操作按钮 |
| --- | --- | --- |
| 确认队列 | 刚加入、等待 AI 分析确认 | 确认沟通 / 打开 / 忽略 |
| 投递队列 | 已确认、等待投递 | 撤回 / 打开 / 忽略 |
| 投递中 | 正在投递流程 | 批准 / 重试 / 打开 / 忽略 / 跳过 |
| 失败 | 投递失败 | 批准 / 重试 / 打开 / 忽略 / 跳过 |
| 已投递 | 完成 | 灰置「已投递」 |
| 已跳过 / 已忽略 | 被过滤或用户忽略 | — |

- **确认沟通**：把岗位从「确认队列」移入「投递队列」；会自动从简历中心匹配打招呼语，**若没有招呼语会提示「请先填写求职招呼语，再确认沟通」**
- **打开**：右栏浏览器跳转到该岗位页面
- **忽略 / 跳过**：不再处理该岗位
- **重试**：失败岗位重新投递。⚠️ **触发过风控的岗位**「重试」被禁用，提示：「该岗位曾触发平台风控拦截（验证/封禁），禁止重试，请人工核对」
- **撤回**：从投递队列退回确认队列

### 6.5 三种投递方式

1. **人工确认（推荐首次）**：逐条点「确认沟通」→ 岗位进入投递队列 → 点「**一键投递**」→ 浏览器自动打开岗位 → AI 草稿预填沟通框 → **由你亲自点发送**
2. **自动辅助 / 全自动投递**：在「设置 → 常规与外观 → 执行模式」切到「全自动投递」后，按匹配优先级依次投递队列；**队列为空时会自动触发采集**；失败自动暂停交人工核对
3. **自动沟通**：见下一节（侧栏「自动沟通」入口），真实浏览器自动打开窗口、输入并发送打招呼语

### 6.6 消息与日志控制台（中栏底部）

- 「**消息与日志**」实时滚动：时间戳 + 级别 + 消息
- 级别过滤：ALL / INFO / SUCCESS / WARN / ERROR
- 操作：「清空」「回到最新」
- 关键提示场景：
  - 风控自动暂停：「若右侧浏览器出现安全验证，请人工完成后再点『重新投递』」
  - 达上限：「今日已投递 N 条，达到安全上限 N 条，投递已暂停（避免账号受限）」

### 6.7 首页的「任务控制中心」

「首页」页同样提供全局控制：**开始投递**（运行中变「暂停」）、**停止**、**新建任务**、**批量确认**、**全部忽略**、**管理方向**、**失败恢复**；以及「今日投递目标」进度条（建议分时段投递：早/午/晚，避免触发平台风控）。

## 七、第六步：自动沟通（批量打招呼）

点击侧栏「**自动沟通**」：

### 7.1 顶部状态 pill

- `模式：全自动投递 / 人工确认`
- `隐身引擎已就绪 / 引擎未就绪`
- `安全监控正常 / 风控冷却中`

### 7.2 操作按钮

- 「**开始批量沟通**」（运行中变「**停止沟通**」）——按匹配优先级依次处理队列岗位
- 「**检测状态**」——检查引擎与登录状态
- 「**扫码登录**」/「**退出登录**」——管理 Camoufox 登录态（退出需 Modal 确认「退出 Camoufox 登录态？」）

### 7.3 沟通队列

每条记录：打招呼语（可编辑）、「**沟通**」/「已沟通」、「**打开岗位**」、「**重试**」（仅失败且非风控时可重试）。指标：待沟通 / 已沟通 / 失败。

### 7.4 实时沟通专属终端日志

- 搜索框（搜索岗位 / 公司 / 消息）
- Segmented 过滤：全部 / 💬招呼 / ✅成功 / ⚠️风控 / ❌失败
- 「清空」按钮

### 7.5 沟通与附件设置（右侧面板）

| 设置项 | 说明 |
| --- | --- |
| 发送简历图片附件 | Switch；「图片简历附件 (N/4)」上传 JPG/PNG，单个 ≤1MB，最多 4 张 |
| 发送在线简历 | Switch |
| 排除猎头岗位 | Switch |
| 打招呼语提示词 | 「保存」「默认」 |

### 7.6 防封号节奏限制（右侧面板，重要）

| 参数 | 默认值 |
| --- | --- |
| **每日沟通上限**（maxDailySent） | 120 条/日（安全上限 150，取二者较小值） |
| **岗位间隔**（betweenJobsSeconds） | 20 秒 |
| **每分钟动作数**（maxActionsPerMinute） | 6 次/分 |
| **风控冷却**（autoCooldownMinutes） | 30 分钟 |

> 自动沟通发送结果以**聊天窗口出现自己的文字气泡**为准：未确认气泡不计成功；出现安全验证（code 35 等）立即停止交人工，绝不自动重试。

## 八、任务进度与失败恢复

点击侧栏「**任务进度**」：

- **执行任务列表**：方向名、关键词、城市、进度条、状态 Tag（已完成 / 失败 / 进行中）
- 筛选 Segmented：全部 / 确认队列 / 投递中 / 已投递 / 失败 / 已忽略（带计数）+「显示已忽略 / 已跳过」+「当前显示 N / N 个岗位」
- 岗位记录：状态 Tag（确认队列 / 投递队列 / 投递中 / 已投递 / 失败 / 已跳过 / 不推荐 / 已忽略）、AI 分数、匹配决策、拦截硬条件、存在缺口、进度条
- 操作：「**查看详情**」「**重试**」「**忽略**」「**跳过**」「**批准投递**」；右上「**去工作台**」快捷跳转

> 任务内部阶段（进度条含义）：已发现岗位 12 → 读取岗位详情 24 → AI 匹配分析 42 → AI 分析完成 56 → 等待人工确认 60 → 等待投递 64 → 等待重新投递 66 → 打开岗位页面 70 → 打开沟通窗口 78 → 已打开沟通窗口等待发送/核对 80 → 核对 HR 与岗位 82 → 填写求职招呼语 86 → 发送求职招呼语 90 → 确认文字已发送 94 → 发送简历附件 97 → 确认投递结果 98 → **投递成功 100**。

## 十、定制简历（求职助手）

点击侧栏「**定制简历**」，针对目标岗位一键定制简历内容：

### 10.1 输入岗位信息

- **岗位信息卡**：岗位名称（如：前端开发工程师（实习））+ 岗位职责与任职要求全文（内容越完整，定制越精准）
- 可从已批准岗位一键导入：`（可选）从已批准岗位导入` 选择框
- 粘贴 JD 后若检测到页面噪声，会提示「检测到页面噪声」并提供「一键清理」按钮（复用岗位采集的 jdCleaner 清洗规则）
- 点击「**生成定制简历**」开始分析

### 10.2 匹配评估

- 生成前先做**实时匹配评估**：岗位关键词 vs 简历命中情况（绿色=简历已覆盖、金色=画像中有但简历缺失、红色=完全缺失），并给出匹配分
- 定制完成后对比定制前后匹配分变化（提升 +N / 下降 / 基本持平 Tag）

### 10.3 定制结果

- 每条结果标注来源：`AI 生成` 或 `本地规则兜底`（AI 输出不达标自动回退，仅引用简历真实事实）
- **定制摘要**：「定制个人摘要」编辑区，可修改后保存
- **量化经历**：原简历 + 定制后内容对照展示
- **突出技能**：绿色 Tag 列表
- **技能缺口**：橙色 Tag 列表（如实列出 JD 要求但简历缺失的能力）
- **定制求职信（打招呼语）**：第一人称口吻，可「**存入打招呼语**」（写入简历中心的打招呼语，供自动沟通使用）或重新生成
- **历史定制记录**：可查看 / 重新加载 / 删除

## 十一、OpenClaw（可选本地桥接）

点击侧栏「**OpenClaw**」：

- 状态卡：版本 / 运行中 / 已暂停 / 解析器 / 事件数 / 数据库
- 按钮：「**刷新状态**」「**启动**」「**暂停**」「**停止**」「**查看日报**」「**查看日志**」
- 未连接时提示：「OpenClaw 未连接，请先点击『启动』」
- **扫描版 PDF / 特殊字体 OCR**：「选择 PDF 文件」→「**解析**」→ 得到 OCR 文本
- 日报、桥接日志（events / commands）卡片展示

> 普通使用（岗位分析、沟通草稿、人工确认）**不需要** OpenClaw；它用于 OCR、日报、任务状态恢复等增强能力。

## 十二、常见操作速查

| 我想… | 怎么做 |
| --- | --- |
| 换 AI 服务商 | 设置 → LLM 配置 → 服务商预设 → 测试连接 |
| 改打招呼语 | 简历中心 → AI 打招呼语提示词 → 编辑并保存 |
| 针对岗位定制简历 | 定制简历 → 粘贴 JD（或从已批准岗位导入）→ 生成定制简历 |
| 定制求职信存为招呼语 | 定制简历 → 定制求职信 → 存入打招呼语 |
| 管理 AI 技能 | 设置 → AI 技能（Skills 层）→ 启停 / 导入 SKILL.md / 新建技能 |
| 不让某公司投递 | 设置 → 求职偏好 → 公司/招聘方黑名单 |
| 只投某个城市 | 设置 → 求职偏好 → 目标城市 + 城市反选黑名单 |
| 调低投递频率 | 自动沟通 → 防封号节奏限制（间隔/每分钟动作数） |
| 恢复失败的岗位 | 任务进度 → 重试 / 批准投递 |
| 清理全部数据 | 设置 → 数据管理 → 清空全部数据（有二次确认） |
| 换隐身引擎 | 设置 → 隐身引擎与桥接 → 底座引擎（WebView/CloakBrowser/Camoufox） |
