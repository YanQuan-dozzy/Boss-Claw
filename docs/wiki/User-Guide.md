# 功能指南 · BossClaw 详细操作手册

本文是 BossClaw 的**完整上手操作手册**，按「界面总览 → 首次配置 → 简历 → 画像 → 投递方向 → 工作台投递 → 自动沟通 → 任务进度 → 统计 → 定制简历 → OpenClaw」的顺序，手把手教你怎么操作这个软件。文中所有按钮、标签文字均与软件界面一致。

---

## 一、界面总览

启动 BossClaw 后是一个单窗口桌面应用，分四个区域：

```
┌──────────────────────────────────────────────────────────────┐
│ ① 标题栏：BossClaw 桌面版 · 投递引擎状态 · 主题切换 · 窗口按钮  │
├──────────┬───────────────────────────────────────────────────┤
│ ② 侧栏   │  ③ 主内容区（工作台=三栏；其余页面=双栏）          │
│  (11入口) │                                                   │
├──────────┴───────────────────────────────────────────────────┤
│ ④ 状态栏：OpenClaw 状态 · BOSS 登录态 · 投递统计              │
└──────────────────────────────────────────────────────────────┘
```

### ① 标题栏
- 左侧：BossClaw 图标 +「BossClaw 桌面版」+ 状态灯 + 引擎文案（`投递引擎 · 运行中 / 已停止 / 未连接`）
- 右侧：主题切换胶囊按钮（**浅色 / 深色 / 跟随系统**）+ 最小化 / 最大化 / 关闭按钮
- 双击标题栏空白处可最大化 / 还原窗口

### ② 功能侧栏（11 个入口，从上到下）

| 顺序 | 入口 | 作用 |
| --- | --- | --- |
| 1 | 首页 | 运行状态概览、快捷入口、任务控制、最近动态、今日投递目标（各启用平台合计） |
| 2 | 工作台 | **核心投递页（三栏）**：岗位队列 + 内置浏览器 |
| 3 | 简历中心 | 导入简历、AI 打招呼语提示词、职业画像 |
| 4 | 投递方向 | 勾选岗位方向、搜索词、优先级 |
| 5 | 任务进度 | 任务列表、异常任务失败恢复 |
| 6 | 定时任务 | 定时投递 / 采集 / 备份 + 分批投递模板 |
| 7 | 数据统计 | 投递指标与可视化图表 |
| 8 | 定制简历 | 输入岗位 JD，生成定制摘要 / 量化经历 / 求职信 / 技能缺口 |
| 9 | OpenClaw | 本地桥接（OCR / 日报 / 日志） |
| 10 | 自动沟通 | 批量自动打招呼 / 投递（多平台，真实浏览器引擎） |
| 11 | 设置 | 常规外观、招聘平台、求职偏好、AI/LLM、隐身引擎、数据管理 |

侧栏底部固定显示 `OpenClaw 已连接 / 未连接` 状态灯；侧栏可收起（点击「收起侧边栏」），折叠后悬停按钮可展开。

### ④ 状态栏
- 左侧：`OpenClaw 已连接/未连接`、`BOSS 已登录 / 未登录 / 检测中`
- 右侧：`已投递 N · 已跳过 N · 确认队列 N`（实时统计）

## 二、第一步：完成设置（所有功能的前提）

点击侧栏「**设置**」，从左到右依次检查 6 个分区：**常规与外观 / 招聘平台 / 求职偏好 / AI / LLM 配置 / 隐身引擎与桥接 / 数据管理**：

### 2.1 常规与外观

| 设置项 | 说明 |
| --- | --- |
| 执行模式 | Segmented 切换：**人工确认（半自动）** / **全自动投递**。首次使用请选「人工确认」，熟悉后再切全自动 |
| 界面主题 | 浅色 / 深色 / 跟随系统 |
| 内置浏览器标签页管理 | 「自动关闭闲置标签页」开关 + 闲置关闭阈值（默认 5 分钟） |

### 2.2 招聘平台（多平台开关与独立配额）

| 设置项 | 说明 |
| --- | --- |
| 平台启用 | BOSS 直聘 / 猎聘 / 智联招聘 / 前程无忧 各平台 Checkbox 勾选启用；BOSS 同样可取消勾选，但**至少保留一个启用平台**（唯一启用平台不可取消）。取消勾选后该平台不再参与搜索采集与自动沟通，已采集岗位保留，重新启用后继续处理 |
| 平台优先级 | ↑/↓ 调整（1 = 最高）：决定工作台搜索栏的平台顺序与多平台执行顺序——自动沟通会**先完成高优先级平台的全部已确认任务，再切换下一优先级平台** |
| 每日投递目标 | 每平台独立配额（0 = 不限）：BOSS / 猎聘 / 前程无忧默认 **120/日**，智联 **100/日**；实际上限 = min(每日目标, 平台侧上限, 安全上限 150)，智联平台侧约 100/日，输入值超限自动按上限执行 |
| 登录状态 | 每平台两行：工作台（内置浏览器）登录态 + 自动沟通（Camoufox）登录态 |
| 扫码登录 / 退出 | 「扫码登录」→ 工作台内置浏览器新标签打开该平台登录页（Electron 分区会话持久化，免重复登录）；「退出」清除内置浏览器会话 |
| 平台提示 | 各平台投递语义 / 限制提示（如猎聘需先在 App 设招呼语、智联 ~100/日上限、前程无忧按批量投递计数） |

> **投递通道**：工作台「一键投递」仅处理 **BOSS 直聘**岗位；猎聘 / 智联 / 前程无忧岗位确认后由「自动沟通」引擎（Camoufox）投递，因此**投递前需在「自动沟通」页完成对应平台 Camoufox 登录**（Cookie 按平台存 `~/.bossclaw/camoufox-cookies-{平台}.json`）。非 BOSS 平台的搜索采集同样只能走 Camoufox 隐身采集。

### 2.3 求职偏好（过滤与投递条件的核心）

| 设置项 | 默认值 / 说明 |
| --- | --- |
| 目标城市 | 逗号分隔，如 `深圳,广州` |
| 薪资期望 | 如 `15k-25k` |
| 求职类型 | 不限 / 全职 / 实习 / 校招 / 兼职 |
| 学历要求 | 不限 / 大专 / 本科 / 硕士 / 博士 |
| 经验要求 | 按需填写 |
| **每日投递目标** | 已**按平台**配置：见上方「2.2 招聘平台」各平台「每日投递目标」（BOSS / 猎聘 / 前程无忧默认 120/日、智联 100/日），建议分时段投递，避免触发风控 |
| **最低匹配要求分**（minScore） | 默认 **75**，低于此分的岗位不推荐 |
| HR 活跃度过滤 | 不限 / 本月活跃及以上 / 本周 / 3 日内 / 今日 / 刚刚活跃及以上 / 仅在线 |
| 面试方式筛选 | 不限 / 仅线上 / 仅线下 |
| 城市反选黑名单 | 排除省份 / 排除城市（勾选后自动跳过这些地区的岗位） |
| 公司 / 招聘方黑名单 | 命中即自动跳过 |
| 搜索采集范围控制 | 自动下拉加载、最大轮数（默认 12）、滚动间隔（默认 1500ms 滑块）、断点续采序号 |

> 这里的过滤条件会在「加入任务」入队时**自动生效**：HR 活跃度不达标、猎头岗位、城市被排除、公司命中黑名单、面试方式冲突的岗位会直接标记「已跳过」，并在日志中说明原因。

### 2.4 AI / LLM 配置（AI 能力的前提）

| 设置项 | 说明 |
| --- | --- |
| 服务商预设 | 下拉选择：OpenAI / DeepSeek / 通义千问 / 智谱 GLM / 硅基流动 / 火山方舟 / **自定义（OpenAI 兼容）** |
| Base URL / 模型名称 / API Key | 按服务商填写；Key 只保存在本机 |
| 测试连接 | 填写后点击测试，通过后再保存 |
| AI 结果缓存 | 本机缓存（条数 / 命中 / 占用 KB +「清空缓存」）；服务端缓存（请求数 / 命中 tokens +「清零统计」） |

> **没有 AI Key 也能用吗？** 可以，但职业画像、AI 匹配、沟通草稿会降级为本地规则，建议配置一个 Key 以获得完整体验。

### 2.5 AI 技能（Skills 层，位于「AI / LLM 配置」分区）

| 设置项 | 说明 |
| --- | --- |
| 内置技能 | 6 个标准 SKILL.md 技能：`resume-profile`（简历画像）/ `job-analysis`（岗位分析）/ `greetings`（打招呼语）/ `tailor-cv`（定制简历）/ `great-resume`（经历酥化，assistant）/ `job-match`（证据驱动匹配，job-analysis），按任务作用域自动注入 AI 提示词；后两个为增强技能、默认关闭，可在设置页手动启用 |
| 启用开关 | 每个技能可独立启停；关闭后对应 AI 调用的增强约束不再注入，开关变化会使相关 AI 缓存自动失效 |
| 导入 SKILL.md | 选择标准 SKILL.md 文件（frontmatter + 正文）导入为自定义技能 |
| 新建技能 | 弹窗表单：名称 + 绑定作用域 + 指令正文（注入 system prompt） |
| 自定义技能 | 保存在本机用户数据目录（`userData/skills`），可停用 / 删除（内置技能不可删除），带紫色「自定义」Tag |
| 恢复默认 | 一键恢复全部技能为默认启用 |

### 2.6 隐身引擎与桥接（可选，默认关闭）

| 设置项 | 说明 |
| --- | --- |
| 底座引擎 | Segmented：**WebView（默认）** / CloakBrowser / Camoufox |
| CloakBrowser 面板 | 「检测状态」「停止引擎」（首次启用自动下载约 200MB 隐身 Chromium） |
| Camoufox 面板 | 「检测状态」「停止桥」、指纹伪装系统（Windows 推荐 / macOS / Linux）、隐身搜索页数（1-5）、优先隐身通道、「隐身扫码登录」「退出登录」 |
| OpenClaw 本地桥接 | 「刷新状态」「前往 OpenClaw 管理页」 |

> 隐身引擎仅用于降低「正常操作被误判为机器人（环境异常 code 37）」的概率，**不绕过**验证码与账户验证（code 35 / 36 / 32 仍立即停止交人工）。

### 2.7 数据管理

- **导出 JSON 备份**：把全部本地数据（简历、画像、方向、任务、统计、设置）导出为 JSON 文件
- **导入 JSON 备份**：恢复之前的备份
- **本地自动备份**：`localStorage` 为主存储；设置页可「选择备份目录 / 立即备份 / 从本地备份恢复」。应用每 5 分钟脏检查把关键持久数据写盘到备份目录（默认 `userData/backup`），内容未变化不重写；仅当 `localStorage` 缺失 / 被清空时才从本地备份自动回签恢复
- **开机自启动**：设置页开关（Windows 登录项，打包安装版生效），可配合「定时任务」在应用运行期间自动投递 / 采集 / 备份
- **清空全部数据**：危险操作，弹出确认 Modal（含不可恢复警告），清空后需重新配置（同时删除本地备份文件）

## 三、第二步：导入简历（简历中心）

1. 点击侧栏「**简历中心**」
2. 点击「**导入文件**」按钮（已有文本时变为「**重新导入**」），或把文件拖拽到拖拽区（提示：「点击或拖拽简历文件到此处」「100% 本地安全解析 · 单个文件 ≤ 10MB」）
3. 支持格式：**PDF / DOCX / TXT**（全部本地解析，不经过网络）；旧版 `.doc` 格式请先用 Word/WPS 另存为 `.docx` 或 `.pdf`
4. 解析成功后，原文显示在编辑区，可修改；点击「**保存原文**」保存

> 解析方法会以蓝色 Tag 标注（如 PDF 自研解析器 / mammoth 等）。

---

## 四、第三步：生成职业画像 + 打招呼语

仍在「简历中心」页，往下滚动：

### 4.1 AI 打招呼语提示词

- 8 行提示词编辑器，可「**生成预览**」「**保存提示词**」「**恢复默认**」「**清空预览**」
- 预览区展示 4 条打招呼语，每条可「**复制**」
- 界面注明：「请勿替用户承诺薪资、到岗或面试时间」

### 4.2 职业画像（可编辑草稿）

1. 点击「**生成职业画像**」——AI 生成初稿（失败自动降级到本地规则）
2. 核对并编辑以下字段：
   - **个人定位摘要**
   - **主方向**（最多 3 个）
   - **搜索关键词**（真实岗位名，最多 12 个）
   - **技能 / 城市 / 求职类型 / 学历 / 经验 / 薪资 / 排除方向**
3. 点击「**保存**」。保存校验：**画像至少需要一个主方向和至少一个搜索词**，否则无法保存

> 职业画像必须基于真实简历信息，删除任何夸大或不实的内容。

## 五、第四步：确认投递方向（投递方向）

1. 点击侧栏「**投递方向**」
2. 看到方向卡片列表，每张卡片包含：
   - 启用 Switch、名称、`自定义/画像` Tag、`#优先级`、删除按钮（需二次确认「删除投递方向」）
   - 「搜索词」输入框（输入后**回车添加**搜索关键词）
   - 匹配技能、能力缺口展示
   - 上下箭头调整优先级
3. 三种操作：
   - 「**根据画像更新**」：从职业画像重新生成方向
   - 「**新增自定义方向**」：弹窗填写（如：游戏前端开发）
   - 「**确认方向（N）**」：**必须点击确认**，系统只对已确认的方向建立任务；未确认会提示「请至少勾选一个投递方向」
4. 确认后显示绿色 Tag「已确认」

---

## 六、第五步：工作台投递（核心操作）

点击侧栏「**工作台**」，这是三栏布局：`[侧栏] │ [中栏：岗位进度+列表+日志] │ [右栏：内置浏览器]`。

### 6.1 用内置浏览器找岗位

1. 右栏浏览器默认打开 BOSS 直聘（`https://www.zhipin.com`）；启用多平台后，工具栏「新标签页」下拉可选猎聘 / 智联招聘 / 前程无忧首页；首次使用需**登录**（各平台登录态本地持久化，之后免重复登录）
2. 工具栏：后退 / 前进 / 刷新 / 在系统浏览器中打开 / 地址栏（前缀「链接」，回车跳转）/「**前往**」/ 平台首页下拉 +「新标签页」（开启的平台显示为 加号图标右侧下拉）
3. 搜索并打开**某个岗位的详情页**
4. 点击工具栏「**加入任务**」→ 岗位进入中栏「确认队列」（岗位卡片带平台标识 chip：BOSS 绿 / 智联蓝 / 猎聘橙 / 前程无忧紫）

> ⚠️ 如果在**岗位列表页**点「加入任务」，会提示：「当前是岗位列表页（含多个岗位）。请点击具体岗位进入详情页后，再点『加入任务』加入单个岗位」。请先进详情页。

### 6.2 岗位进度卡（中栏顶部）

- **阶段条**：`搜索 → 匹配 → 确认 → 投递 → 完成` 五段，已完成阶段带岗位计数
- **6 个统计块**（互不重叠）：搜索中、待确认、待投递、投递中、已完成、失败
- 右上角先选**采集平台**（多选下拉「选择采集平台」，仅显示已启用平台、按平台优先级排序，至少保留一个）：单选 BOSS →「**搜索采集**」（启用 Camoufox 时显示「**隐身采集**」）；多选 →「**采集 N 平台**」按所选平台**串行采集**；运行中按钮变红「**停止**」
- 采集中有实时进度条（N/M）与状态 Tag：准备中 / 滚动中 / 点击中 / 完成（隐身采集中显示对应状态），以及「暂停/继续」
- 投递中的 active 卡片：显示岗位名、平台 chip、阶段进度 %、「**打开岗位**」「**暂停投递**」按钮

> **采集通道**：BOSS 走内置浏览器可视化采集（启用 Camoufox 时可分流隐身采集）；**猎聘 / 智联 / 前程无忧只能走 Camoufox 隐身采集**（webview 可视化采集为 BOSS 专属链路），采集前须在「自动沟通」页完成对应平台 Camoufox 登录。

### 6.3 岗位列表（中栏中部）

- 筛选 Segmented：`全部 N / 待确认 N / 待投 N / 投递中 N / 已投 N / 失败 N`，可勾选「**显示已忽略/跳过**」
- 批量按钮：「**一键投递**」（有待投岗位才亮起）、「**批量确认**」、「**全部忽略**」
- 提示条：「待确认岗位按 AI 匹配分从高到低排列；确认沟通前可直接修改求职招呼语。」
- 每张岗位卡片显示：**平台 chip**（BOSS 绿 / 智联蓝 / 猎聘橙 / 前程无忧紫）、标题+薪资、公司/城市/薪资行、**AI 评分** chip、`#优先级`、决策文案（**推荐 / 谨慎 / 不推荐**）、`HR 在线` Tag、`线上面试/线下面试` Tag、状态 Tag
- 展开卡片可看到 AI 匹配理由 + 招呼语编辑框（placeholder：「请输入你希望发送给招聘方的求职招呼语」）

> **投递口径**：工作台「一键投递」只处理 **BOSS 直聘**岗位（内置浏览器链路）；猎聘 / 智联 / 前程无忧岗位确认后停留在投递队列，由「自动沟通」批量引擎（Camoufox）按平台优先级投递。

### 6.4 岗位状态与单条操作

| 状态 Tag | 含义 | 可用的操作按钮 |
| --- | --- | --- |
| 确认队列 | 刚加入、等待 AI 分析确认 | 确认沟通 / 打开 / 忽略 |
| 投递队列 | 已确认、等待投递 | 撤回 / 打开 / 忽略 |
| 投递中 | 正在投递流程 | 批准 / 重试 / 打开 / 忽略 / 跳过 |
| 失败 | 投递失败 | 批准 / 重试 / 打开 / 忽略 / 跳过 |
| 已投递 | 完成 | 灰置「已投递」 |
| 已跳过 / 已忽略 | 被过滤或用户忽略 | — |

- **确认沟通**：把岗位从「确认队列」移入「投递队列」；会自动从简历中心匹配打招呼语，**若没有招呼语会提示「请先填写求职招呼语，再确认沟通」**
- **打开**：右栏浏览器跳转到该岗位页面
- **忽略 / 跳过**：不再处理该岗位
- **重试**：失败岗位重新投递。⚠️ **触发过风控的岗位**「重试」被禁用，提示：「该岗位曾触发平台风控拦截（验证/封禁），禁止重试，请人工核对」
- **撤回**：从投递队列退回确认队列

### 6.5 三种投递方式

1. **人工确认（推荐首次）**：逐条点「确认沟通」→ 岗位进入投递队列 → 点「**一键投递**」（BOSS 岗位）→ 浏览器自动打开岗位 → AI 草稿预填沟通框 → **由你亲自点发送**
2. **自动辅助 / 全自动投递**：在「设置 → 常规与外观 → 执行模式」切到「全自动投递」后，按匹配优先级依次投递队列；**队列为空时会自动触发采集**；失败自动暂停交人工核对
3. **自动沟通（多平台）**：见下一节（侧栏「自动沟通」入口），真实浏览器按平台语义自动沟通 / 投递（BOSS 聊天、猎聘「聊一聊」App 招呼、智联 / 前程无忧投递简历）

> 猎聘 / 智联 / 前程无忧岗位的投递**必须由「自动沟通」引擎执行**（对应平台需已 Camoufox 登录）；仅启用 BOSS 时，第 1、2 种方式即可完成全部投递。

### 6.6 消息与日志控制台（中栏底部）

- 「**消息与日志**」实时滚动：时间戳 + 级别 + 消息
- 级别过滤：ALL / INFO / SUCCESS / WARN / ERROR
- 操作：「清空」「回到最新」
- 关键提示场景：
  - 风控自动暂停：「若右侧浏览器出现安全验证，请人工完成后再点『重新投递』」
  - 达上限：「今日已投递 N 条，达到安全上限 N 条，投递已暂停（避免账号受限）」

### 6.7 首页的「任务控制中心」

「首页」页同样提供全局控制：**开始投递**（运行中变「暂停」）、**停止**、**新建任务**、**批量确认**、**全部忽略**、**管理方向**、**失败恢复**；以及「今日投递目标」进度条（**今日目标 = 各已启用平台每日目标合计**，仅启用 BOSS 时即原 120；建议分时段投递：早/午/晚，避免触发平台风控）。

## 七、第六步：自动沟通（多平台批量打招呼 / 投递）

点击侧栏「**自动沟通**」：

### 7.1 顶部状态 pill

- `模式：全自动投递 / 人工确认`
- `隐身引擎已就绪 / 引擎未就绪`
- `安全监控正常 / 风控冷却中`

### 7.2 平台卡片（多平台，各平台独立登录）

- 「**隐身引擎投递控制**」卡片内展示各已启用平台的状态卡片（BOSS 直聘 / 猎聘 / 智联招聘 / 前程无忧，按设置优先级排序）：每张卡显示 `平台名 + 引擎就绪状态 + 登录态（已登录 / 未登录 / 引擎未就绪）`，并提供「**登录** / **退出**」按钮——登录唤起 Camoufox 可见窗口扫码，Cookie 按平台持久化（`~/.bossclaw/camoufox-cookies-{平台}.json`）
- 批量沟通开始前会逐平台校验：引擎未就绪或未登录的平台会提示并跳过（请先完成该平台登录）

### 7.3 操作按钮

- 「**开始批量沟通**」（运行中变「**停止沟通**」）——按**平台优先级串行**处理队列岗位：先完成高优先级平台的全部已确认（approved）岗位，再自动切换下一平台；只处理当前仍启用的平台
- 「**检测状态**」——检查引擎与各平台登录状态
- 批量进度条显示 `N / M` 与「独立窗口自动化沟通中...」Tag（进行中请勿遮挡浏览器窗口）

### 7.4 沟通队列

每条记录：平台 chip、打招呼语（可编辑）、「**沟通**」/「已沟通」、「**打开岗位**」、「**重试**」（仅失败且非风控时可重试）。指标：待沟通 / 已沟通 / 失败。

### 7.5 实时沟通专属终端日志

- 搜索框（搜索岗位 / 公司 / 消息）
- Segmented 过滤：全部 / 💬招呼 / ✅成功 / ⚠️风控 / ❌失败
- 「清空」按钮

### 7.6 沟通与附件设置（右侧面板）

| 设置项 | 说明 |
| --- | --- |
| 发送简历图片附件 | Switch；「图片简历附件 (N/4)」上传 JPG/PNG，单个 ≤1MB，最多 4 张 |
| 发送在线简历 | Switch |
| 排除猎头岗位 | Switch |
| 打招呼语提示词 | 「保存」「默认」 |

### 7.7 防封号节奏限制（右侧面板，重要）

| 参数 | 默认值 |
| --- | --- |
| **岗位间隔**（betweenJobsSeconds） | 20 秒 |
| **每分钟动作数**（maxActionsPerMinute） | 6 次/分 |
| **风控冷却**（autoCooldownMinutes） | 30 分钟 |

> **每日沟通上限已按平台独立配置**（在「设置 → 招聘平台」各平台「每日投递目标」中设置，BOSS / 猎聘 / 前程无忧默认 120/日、智联 100/日，互不挤占），不再在本面板设置；本面板只控制动作节奏。
> 自动沟通发送 / 投递结果以平台成功确认为准（BOSS 聊天窗出现自己的**文字气泡**、猎聘聊天窗打开 /「继续聊」、智联 / 前程无忧「投递成功」/「已投递」）：未确认不计成功；出现安全验证（code 35 等）立即停止交人工，绝不自动重试。

## 十、定时任务（分时分批投递）

点击侧栏「**定时任务**」：按设定的时刻自动触发「投递 / 采集 / 备份」，需保持应用运行（**最小化也生效**，窗口关闭则不执行）。早中晚分批现由多条「限量定时投递」表达。

### 10.1 分批投递模板（一键创建）

- 「分批投递 = 把一天的投递量分散到多个时刻，各自触发一轮**限量**投递，避免单次批量触发平台风控。」
- 点击「**一键创建 早/午/晚 三条投递任务**」生成：早间 09:00 / 午间 13:00 / 晚间 18:00 三条「投递」任务（默认每轮 40 条、全部启用平台），随后可逐条编辑时刻、每轮上限与目标平台
- 执行仍受每日上限 / 平台配额、冷却与首条验收等安全规则约束；已存在同名模板任务时不会重复创建
- 老版本设置的「分批投递」（config.batchDelivery）会在应用启动时**一次性迁移**为「早间 / 午间 / 晚间限量投递」三条任务，无需手动重建

### 10.2 新建 / 编辑任务

弹窗表单字段：

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 自定义，如「每日早晨投递」 |
| 动作类型 | 投递 / 采集 / 备份（含简要说明） |
| 目标平台 | 投递与采集可选（多选下拉，可预选未启用平台，启用后自动生效）；**留空 = 全部已启用平台** |
| 本次投递上限（单轮） | 仅投递类型：`条 / 轮`，0 = 不限。>0 时到点触发后成功沟通满该数即自动结束本轮，等待下一次触发时刻——配合多个时刻即构成「分批投递」 |
| 触发时刻 | HH:mm（分钟步进 5） |
| 执行星期 | 多选，留空 = 每天 |

### 10.3 列表与运行规则

- 任务行显示：名称 + 动作 Tag（投递 / 采集 / 备份）+ 平台 Tag（圈定平台或「全部平台」）+「≤N/轮」Tag + 触发时刻 / 星期 + 上次触发时间；可 编辑 / 启停 Switch / 删除
- **定时投递**：复用自动投递引擎全部安全守卫（冷却、每日上限、平台配额、首条验收、风控交人工）；若触发时刻已有批量沟通在运行则跳过本次、下个触发时刻再试
- **定时采集**：按任务圈定的平台逐一执行（需对应平台已登录 / Camoufox 登录）
- **定时备份**：写入「设置 → 数据管理」配置的本地备份目录（内容未变化不重写文件）
- 调度器每 15 秒心跳扫描，按目标时刻去重（同一分钟只触发一次），关闭后台节流保证最小化仍触发

## 十一、定制简历（求职助手）

点击侧栏「**定制简历**」，针对目标岗位一键定制简历内容：

### 10.1 输入岗位信息

- **岗位信息卡**：岗位名称（如：前端开发工程师（实习））+ 岗位职责与任职要求全文（内容越完整，定制越精准）
- 可从已批准岗位一键导入：`（可选）从已批准岗位导入` 选择框
- 粘贴 JD 后若检测到页面噪声，会提示「检测到页面噪声」并提供「一键清理」按钮（复用岗位采集的 jdCleaner 清洗规则）
- 点击「**生成定制简历**」开始分析

### 10.2 匹配评估

- 生成前先做**实时匹配评估**：岗位关键词 vs 简历命中情况（绿色=简历已覆盖、金色=画像中有但简历缺失、红色=完全缺失），并给出匹配分
- 定制完成后对比定制前后匹配分变化（提升 +N / 下降 / 基本持平 Tag）

### 10.3 定制结果

- 每条结果标注来源：`AI 生成` 或 `本地规则兜底`（AI 输出不达标自动回退，仅引用简历真实事实）
- **定制摘要**：「定制个人摘要」编辑区，可修改后保存
- **量化经历**：原简历 + 定制后内容对照展示
- **突出技能**：绿色 Tag 列表
- **技能缺口**：橙色 Tag 列表（如实列出 JD 要求但简历缺失的能力）
- **定制求职信（打招呼语）**：第一人称口吻，可「**存入打招呼语**」（写入简历中心的打招呼语，供自动沟通使用）或重新生成
- **历史定制记录**：可查看 / 重新加载 / 删除

## 十四、安全提醒

- 遇到**验证码 / 安全验证 / 登录异常**（风控码：31 登录失效、32 封禁、35 需安全验证、36 账户异常、37 环境异常、38 环境异常未登录、1006 限速、5002-5004 服务端异常）时，应用会**自动暂停**，请人工处理后继续
- **首次成功投递后应用会强制暂停**，请核对聊天对象、文字气泡与附件
- 不要向任何人透露你的 API Key；不要提交真实简历与个人敏感信息到公开仓库或 Issue
