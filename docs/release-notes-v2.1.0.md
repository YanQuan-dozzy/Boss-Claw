# BossClaw 桌面版 v2.1.0

面向求职者的**本地 AI 投递助手**（Electron + React 桌面应用）。从简历解析、职业画像和岗位方向选择，到岗位信息整理、AI 匹配排序、沟通草稿生成与投递进度管理，集中在一个本地桌面应用中完成。数据本地优先，AI 密钥仅保存在用户本机。

## 本版亮点

- **AI 技能体系（Skills 层）**：标准 SKILL.md 技能文件，内置 `resume-profile` / `job-analysis` / `greetings` / `tailor-cv` 四技能，按任务作用域自动注入 AI 提示词；支持自定义技能导入（SKILL.md）/ 新建 / 删除（存本机 `userData/skills`，白名单防路径穿越）；设置页新增「AI 技能」卡片，启停即生效
- **定制简历求职助手**：侧栏新增「定制简历」入口（第 10 入口），粘贴目标岗位 JD（或从已批准岗位导入）→ AI 生成定制摘要 / 量化经历 / 突出技能 / 技能缺口 / 第一人称求职信；仅引用简历真实事实，AI 输出不达标自动回退本地规则；求职信可一键存入打招呼语
- **岗位匹配增强**：本地确定性多维匹配（硬约束拦截 + 维度评分）与 AI 结果融合，匹配更稳定、可解释
- **岗位采集修复**：岗位信息采集恢复正常；岗位详情自动清洗页面噪音（「去App / 热门职位 / 收藏 / 立即沟通 / 举报」等），jdCleaner 渲染层与 webview 同步
- **工程与发布**：版本升至 2.1.0，productName 统一为 BossClaw；新增 macOS / Linux 打包配置（dmg / zip / AppImage / deb）；README 与 Wiki 全套使用与开发教程同步更新

## 安装

- **系统要求**：Windows 10/11（x64）
- **安装版**：下载 `BossClaw-2.1.0-x64.exe`，双击安装后从开始菜单启动
- **便携版**：下载 `BossClaw-2.1.0-portable.exe`，解压即用，无需安装
- macOS（dmg/zip）与 Linux（AppImage/deb）产物可从源码自行构建

> 首次启动按提示在「设置」页填写求职条件与 AI API Key 即可使用（API Key 仅保存在本机，不会上传）。

## 安全与使用边界

BossClaw 不绕过验证码、不突破任何平台限制、不自动换号。遇到安全验证、登录异常或结果无法确认时立即暂停交人工处理。使用请遵守目标网站规则与账号使用要求。
